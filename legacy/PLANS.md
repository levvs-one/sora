# Sora Legacy

Отдельная ветка `legacy`, отдельные данные, служба и канал обновлений. Перенос интерфейса и возможностей обычной Sora идёт после завершения обычного релиза.

## Проверено

- Общая логика сессий и контракт Sora 1.0.8: настоящий обмен Go ↔ .NET Framework 4.8 на Windows x86 и x64, авторизация, импорт, параллельные запросы, отмена, восемь потоков журнала, отключение и восемь форматов экспорта.
- Сборка Go с Windows 7 SDK 1.26.9, тесты ABI x86/x64, Go race/vet/lint и сборка .NET 4.8/8.
- Зарегистрированная служба x86/x64: SCM PID проверяется до handshake, подменённый канал отвергается до RPC, обычная учётная запись получает доступ, установка и удаление прошли на Windows в CI.
- Новый основной экран .NET 4.8 прошёл запуск на Windows x86/x64 под обычной учётной записью: настоящая служба, одна кнопка добавления при пустом списке, переключение всех 31 языков, три открытия/закрытия и сохранение доступа к службе. Снимок главной получен из настоящего окна. Импорт, выбор серверов и пинг подключены к RPC, но ещё требуют проверки через интерфейс с реальной подпиской.
- SHA256 архивов Xray 26.3.27 Win7 x86/x64, mihomo 1.19.32 x86 go120/x64 v1, sing-box-lx 1.14.3-lx.14 Win7 x86. sing-box-lx x64 собран из закреплённого исходника с Windows 7 SDK; запуск на старой Windows ещё не проверен.

Эти результаты получены на Linux и современной Windows в CI. Они не подтверждают работу на Windows 7 или 8.1.

## Осталось

| Работа | Условие завершения |
| --- | --- |
| Новый интерфейс | Главная, скорость, расширения «Скоро появится», уведомления, правила, журнал, настройки и о приложении; прежний клиент не считается новым интерфейсом |
| Подписки и выбор сервера | Отдельные обновление/пинг/сворачивание, автоматическая смена локации, прямоугольные флаги, одна кнопка добавления при пустом списке |
| Сессии | Очередь с последним выбором и 200 запросов проверены через настоящий RPC. Неподдерживаемый новый план не вызывает предварительного отключения. Остаются реальные сетевые переключения, восстановление и сброс на старой Windows: без оставленных процессов, DNS, прокси и маршрутов |
| Ядра | Настоящий запуск Xray, sing-box и mihomo обоих разрядностей, проверка профилей, XHTTP, TCP/UDP и вариантов стека TUN. Naive/cronet в выбранной legacy-сборке sing-box отсутствует |
| Браузер | Поддерживаемый движок для старой Windows, реальное встраивание, язык запросов, HAR, загрузка/ошибки и освобождение всех принадлежащих ему процессов. Устаревший WebView2/CEF 109 не выдаётся за актуальный браузер |
| Языки | 31 вариант языка интерфейса, поиск по названиям и кодам с выделением совпадений. Названия подписок, серверов и исходные логи не переводятся |
| Журнал и диагностика | Категории, неподвижный просмотр новых строк, автоматические имена экспортов, HAR, EVTX и подходящий для старой Windows захват PCAPNG. Pktmon на Windows 7 отсутствует |
| DPI-обход | Windows-реализация и реальные ограничения Telegram/Discord, DNS и UDP; нельзя считать Linux-only zapret реализованным на Windows |
| Установщики | x86, x64 и universal, подходящие драйверы и runtime, установка/обновление/удаление, контрольные суммы и инструкции |
| Обновления | Только проверенные теги legacy с выбором архитектуры и проверкой SHA256; обычный релиз не предлагается пользователю legacy |
| Проверка старых систем | Изолированные Windows 7 SP1 и Windows 8.1 с необходимыми обновлениями, реальные сайты и сеть. Нужен доступный образ или виртуальная машина; вопрос владельцу уже задан |

Расширения, совместная работа VPN и DPI-обхода, выбор сервера по пропускной способности, сетевые профили, единый DNS-менеджер, управление отдельными соединениями, собственными серверами и синхронизация устройств остаются отдельными работами. Наличие API или экрана не означает готовность функции.

Готового нового legacy-релиза пока нет. Совместимость и отсутствие проблем на старой системе будут заявлены только после её фактической проверки.
