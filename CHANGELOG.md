# Изменения

## 1.1.5 (не выпущено)

Новое:

- «Сообщить о проблеме» в разделе «О приложении» открывает форму ошибки на GitHub с уже указанной версией Sora.

Исправлено:

- Если после выхода из сна или смены сети ядро не удалось перезапустить, Sora показывает ошибку подключения вместо «Подключено». Kill switch остаётся включённым до отключения.
- Вернулся гайд при первом запуске, пропавший в 1.1.3. На последнем шаге только «Назад» и «Готово»; повторить гайд можно в настройках.
- Вернулись предупреждение под QR-кодом подписки, подсказки по исправлению утечки DNS и понятные тексты на экране обновления, в том числе о постепенной раскатке новой версии.
- Обновление: «Отмена» срабатывает до самого запуска установщика, повторная попытка сразу после отмены больше не ломается, а кнопка «Обновить» ждёт окончания проверки. Файлы загрузки, брошенные при закрытии или перезагрузке, удаляются через сутки при запуске.

## 1.1.4 (29 октября 2026)

Новое:

- Поддержка HWID: сохранённые подписки отправляют идентификатор устройства в тех же заголовках, что Happ и v2RayTun, поэтому лимит устройств в Remnawave и других панелях работает с Sora. Идентификатор вычисляется из machine-id системы и не раскрывает ни его, ни имя компьютера. В разделе подписок его можно скопировать, сбросить и отключить для одной подписки или для всех сразу.
- Когда панель отказывает из-за лимита устройств или требует идентификатор, Sora показывает эту причину и сохраняет прежний список серверов вместо пустой подписки.

## 1.1.3 (28 октября 2026)

Новое:

- Подписанные метаданные релизов: приложение и служба проверяют ключ команды Sora, версию, платформу, размер и хеш каждого обновления. Linux повторяет проверку перед установкой и откатом. Версия 1.1.3 становится первым подписанным базовым выпуском; откат на неподписанную 1.1.2 не предлагается.
- Полное приложение для Linux ARM64 вместе с нативной службой; установка и обновление выбирают оба пакета своей архитектуры.
- Windows поставляется с необходимыми библиотеками Visual C++ и обходом DPI ByeDPI без драйвера. Поддержка отдельно подписанных профилей расширений проверяет совместимость до скачивания; для системного фильтра Windows требуется явное согласие.

Исправлено:

- Убраны инструкции и подсказки из интерфейса; ошибки кратко называют только причину на всех 32 языках.
- Первая установка снова работает одной командой на Linux и Windows без заранее установленной Sora. Скрипт загружается по HTTPS, подпись пакетов проверяется доступным системным инструментом; граница доверия первой установки описана в документации.
- Изменения режима, ядра, DNS и правил во время подключения применяются автоматически один раз после короткой паузы. Фоновые обновления не вызывают переподключение; отключение отменяет ожидающие изменения.
- На главной странице показывается только одно действие состояния: повтор очистки, восстановление подключения или восстановление связи со службой. Переходные состояния обходятся без поясняющих плашек.
- Убраны лишние пояснения и устаревшие тексты обновления. Предупреждение строгого kill switch появляется при включении, а в синхронизации отображается имя компьютера без технического идентификатора. Закрытие экрана синхронизации корректно снимает подписку на демон.
- Исправлены запуск и закрытие панелей расширений, проверка разрешений и отмена устаревших запросов. Список соединений отличает отсутствие данных от недоступности движка.
- Удобные отдельные поля своих серверов для каждого протокола, переведённая история уведомлений и точные индикаторы пинга по подписке.
- Ограничены размер, вложенность и параллельная обработка подписок; отменённый импорт не сохраняет данные. Ссылки и учётные данные надёжнее скрываются в журнале и диагностике.
- Усилены проверка локальных полномочий, обработка путей архивов, остановка дочерних процессов и замена файлов при обновлении Windows. Обновлены зависимости и проверки сборки.

## 1.1.2 (23 октября 2026)

Исправлено:

- Ошибки больше не сыплются по каждому поводу. Фоновые сбои (обновление подписки, замеры, короткий перезапуск службы) не показываются, пока не затянулись: подписка показывает статус в своей строке и сообщает только после суток сбоев, служба после 15 секунд недоступности. Одна причина даёт одно уведомление.
- Вместо «Что-то пошло не так» каждая ошибка называет причину и что сделать. Под «Сервер настроен с ошибкой» больше не прячутся десять разных причин.
- Служба останавливается за пару секунд, а не через принудительное завершение по таймауту.
- «Подписка закончится через # день» и текст на другом языке в ошибке спидтеста.

Изменено:

- Компактный экран уведомлений: строки по дням, повторы собираются в одну строку со счётчиком.
- Сортировка списка серверов убрана: серверы всегда идут в порядке подписки. Автовыбор самого быстрого сервера работает как раньше.

## 1.1.1 (22 октября 2026)

Новое:

- Протоколы olcrtc (туннель внутри видеозвонка Jitsi, Яндекс Телемоста или WB Stream), mieru и NaiveProxy: импорт по ссылке, QR-коду и в подписках.
- Подписку можно передать на телефон QR-кодом прямо из списка серверов. Код понимают Happ, v2rayNG, Hiddify и Streisand.
- Свой сервер добавляется в компактном окне: вставьте ссылку, и форма заполнится сама.

Изменено:

- Серверы идут в порядке подписки. Новый режим сортировки «Как в подписке» включён по умолчанию, если вы не выбирали другой.
- Расширение устанавливается в одном окне с процентом загрузки. Расширения команды Sora отмечены галочкой у названия, лишние пояснения убраны.

## 1.1.0 (22 октября 2026)

Новое:

- Магазин расширений: каталог, подписанный ключом команды Sora, установка из файла и по ссылке, разрешения подтверждаются при установке, обновление и откат на предыдущую версию, список отзыва. Расширения добавляют панели, темы, правила маршрутизации и фоновые задачи. Задачи работают в отдельном процессе с ограничением памяти и времени, а сетевые запросы делают только по белому списку адресов и только через VPN.
- Строгий kill switch по желанию: блокировка держится и после сбоя приложения, пока вы явно не отключитесь. К адресам VPN-сервера допускаются только движки Sora.
- Синхронизация подписок, правил и настроек между вашими компьютерами в локальной сети: сопряжение по QR-коду, сквозное шифрование, без аккаунтов и облака.
- Сетевые профили: настройки привязываются к Wi-Fi, шлюзу или провайдеру и применяются сами при смене сети.
- Цепочки из двух или трёх серверов, свои серверы, добавленные вручную, правки поверх подписки (переименовать, скрыть сервер).
- Автовыбор сервера по измеренной скорости или по сочетанию скорости и задержки, переключение при сильной деградации.
- Тест утечек DNS, IPv6 и трафика мимо туннеля с подсказкой, как исправить, и экран соединений с группировкой по программам.
- QR-код подписки и чтение QR с картинки.
- На Linux zapret можно включить вместе с VPN для прямого трафика.
- Поэтапная раскатка обновлений, а на Linux автоматический откат, если новая версия не запустилась.

Исправлено:

- Одиночный IP-адрес в своих правилах теперь работает как адрес, а не как ошибка.
- Проверка пересечения подсетей больше не спорит с собственным адаптером Sora.
- Остановка движка ждёт его завершения дольше и не оставляет процессы.
- Тема и язык «Как в системе» переведены на все языки интерфейса.

- После сброса настроек знакомство с приложением не перекрывает кнопку подключения. Добавлен раздел «Расширения» с надписью «Скоро появится».
- Исправлена связь со службой Windows без запуска приложения от администратора и повторное открытие канала после отключения.
- Выбор локации автоматически переподключает VPN. Частые нажатия применяют последний выбор; отключение отменяет ожидающие переключения.
- Проверка задержки отменяется перед изменением соединения; автоматическая проверка не запускается при включённом VPN.
- Встроенный браузер автоматически повторяет неудачную загрузку два раза. Смена сайта и выход отменяют повтор.

- Новые строки журнала сохраняют положение читаемого текста; плашки сайтов скорости стали вдвое ниже.

- Без подписок на главном экране остаётся одна кнопка добавления. Флаги плоские, кнопка проверки задержки со спидометром, моноширинный шрифт и галочка выбранного сервера убраны.

## 1.0.6 (9 октября 2026)

- Sora работает рядом с другими VPN, например Happ. Свой адаптер она поднимает в свободной подсети, а не в той же, что у соседнего клиента, и не перехватывает его трафик. Проверено для sing-box, Xray и mihomo, в режимах TUN и прокси, рядом с клиентами в стиле Happ и OpenVPN.
- Kill switch закрыт плотнее: DNS не уходит мимо туннеля даже от программ, привязанных к сетевой карте, а адреса fake-IP и адаптера не утекают, если ядро упало.
- После аварии службы при следующем запуске убираются её старые правила маршрутизации, чужие правила не трогаются. Второй запуск службы и диагностические команды больше не ломают работающее подключение.
- Если ядро неожиданно завершилось, в журнал пишется код выхода и последние строки его вывода.
- Новый интерфейс для компьютера: боковая панель с разделами, светлая тема по умолчанию, главный экран без лишнего. Режим работы, kill switch и выбор ядра собраны в одной панели «Режимы».
- Ошибки и события приходят всплывающими уведомлениями справа вверху: они исчезают сами, смахиваются и нажимаются. История хранится в разделе «Уведомления».
- У каждого сервера видны все части протокола, например VLESS | XHTTP | REALITY.
- Объявления провайдера показываются с форматированием и эмодзи.
- Короткое знакомство с приложением при первой установке, его можно повторить из настроек.
- Раздел «Скорость»: Speedtest, Яндекс Интернетометр и ещё десятки сервисов прямо в приложении.
- Без подписки кнопка подключения предлагает добавить подписку или включить режим без сервера.
- Пункт «Сайт подписки» открывает страницу по ссылке, из которой подписка была добавлена.
- В правилах принимаются домены на кириллице, программу можно выбрать из списка установленных.
- Автообновление: Sora сама проверяет новые версии, сверяет файлы по SHA256 и обновляет приложение вместе со службой.

## 1.0.5 (8 октября 2026)

- Kill switch включается вместе с подключением: правила firewall встают до запуска ядра, и в первые секунды ничего не уходит мимо туннеля. Раньше они включались отдельным запросом сразу после подключения.
- Уведомление, когда группа с ролями или выбранный сервер с переключением при сбое перешли на запасной сервер, и когда основной снова отвечает и трафик вернулся на него. Работает с ядром mihomo.
- Ядро возвращает группы и серверы по их id из плана, а не по именам, которые видит mihomo, и берёт задержку каждого сервера группы из его собственной проверки.
- Kill switch, переключённый во время подключения, применяется, когда подключение завершится. Раньше выключение в этот момент обрывало подключение.
- Приложение, переподключившись к службе, продолжает события сессии с того места, где остановилось, и не показывает уведомления повторно.

## 1.0.4 (8 октября 2026)

Первый выпуск нового клиента для Windows и Linux. Версии 1.0.1–1.0.3 были собраны, но не выпущены.

- Приложение для Windows 10 1809+ и 11 (установщик) и Linux (.deb, .rpm, Arch).
- Служба `sora-core` с ядрами sing-box 1.14.2, Xray 26.3.27 и mihomo 1.19.32. Ядро выбирается под каждый сервер автоматически.
- Подписки: обновление по расписанию, трафик и срок, объявления провайдера, свой User-Agent. JSON-подписки Xray (Remnawave).
- Группировка серверов по названиям, порядок по ролям «основной» и «запасной».
- Режимы TUN и системный прокси.
- Kill switch: nftables на Linux, WFP на Windows.
- Переподключение при смене сети и после сна.
- Свои правила для сайтов, IP-адресов и программ, маршруты для России, Ирана и Китая, блокировка рекламы.
- Обход DPI без сервера через zapret (Linux).
- Трей, автозапуск, уведомления.
- Ссылки `sora://`, `happ://add` и ссылки других клиентов открывают добавление подписки.
- Установка одной командой: `install.sh` для Linux, `install.ps1` для Windows.

Старый клиент для Windows 7 и его история изменений находятся в отдельном репозитории [`sora-legacy`](https://github.com/levvs-one/sora-legacy).
