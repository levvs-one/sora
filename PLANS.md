# Планы Sora

Здесь только то, чего в клиенте ещё нет. Готовые функции описаны в [README](README.md) и [истории изменений](CHANGELOG.md).

| Функция | Состояние |
| --- | --- |
| Определение блокировок и обфускация трафика | Номера в контракте зарезервированы (`proto/sora/censor`, `proto/sora/obfs`, см. [architecture.md](docs/architecture.md)), реализации в клиенте нет |
| Сетевые хуки расширений (модули обхода DPI) | Разрешение `net.hooks` объявлено в формате расширений и показано при установке как неактивное, приложение такие модули не запускает |
| Android | Устройство клиента описано в [android-vpnservice.md](docs/android-vpnservice.md), сборки нет |
| Подпись Authenticode | Релизы подписаны Minisign с 1.1.3, но установщик и программы Windows не подписаны сертификатом, SmartScreen может предупреждать |
| Откат обновления на Windows | Автоматический откат после неудачного запуска работает только на Linux |
| Новый интерфейс для старых Windows | Развивается отдельно в [sora-legacy](https://github.com/levvs-one/sora-legacy) |

Пункт считается готовым, когда функция работает у пользователя, а не когда появился экран или API.
