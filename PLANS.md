# Планы Sora

Обычный клиент и legacy развиваются отдельно. Legacy пока отложен.

## Следующие функции

| Функция | Что нужно довести | Приоритет |
| --- | --- | --- |
| Расширения | Раздел с надписью «Скоро появится»; формат расширений, разрешения, установка и удаление ещё не реализованы | P1 |
| Маршрутизация по приложениям и сайтам | Правила уже есть; проверить удобство полноценного split tunneling, выбор программ и доменов на Windows и Linux | P0 |
| Диагностика и восстановление соединения | Обработка смены ядра и потерянной связи есть; автоматическая диагностика после смены сети и восстановления DNS требует отдельной проверки | P0 |
| Автоматический выбор ядра | Совместимость профиля проверяется; выбор ядра с учётом режима и состояния сети нужно расширить | P0 |
| VPN совместно с DPI-обходом | Режим без сервера есть; совместная работа VPN и локального DPI-обхода ещё не реализована | P1 |
| Выбор сервера по скорости | Есть проверка задержки; выбор по измеренной пропускной способности ещё не реализован | P1 |
| Сетевые профили | Отдельные профили для дома, мобильной сети и игр ещё не реализованы | P1 |
| DNS-менеджер | DNS-настройки есть; единый менеджер и проверка утечек для всех режимов ещё не реализованы | P0 |
| Управление соединениями | API просмотра и закрытия соединений есть; полноценный пользовательский экран требует доработки | P1 |
| Собственные серверы | Установка и управление сервером из клиента ещё не реализованы | P2 |
| Синхронизация устройств | Синхронизация настроек и подписок ещё не реализована | P2 |
| Legacy | Новый интерфейс и возможности для старых Windows; отдельная ветка и сборки x86, x64 и universal | P2 |

Подписки, названия серверов и исходные строки журналов не переводятся. Пункты будущих функций не считаются реализованными по одному наличию экрана или API.
