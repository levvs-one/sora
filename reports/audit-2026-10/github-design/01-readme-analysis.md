## Что цепляет (взять)

1. **AmneziaVPN** — один скриншот + 6 коротких пунктов возможностей + кнопки скачивания по ОС. Самая чистая структура среди клиентов.
2. **v2rayNG** — GPG-отпечаток прямо в README (сигнал доверия, 5 строк). Предельная сухость: ни одного маркетингового слова.
3. **sing-box** — доказательство, что можно вообще без воды: 1 строка + ссылка на доки. Не копировать буквально (это ядро, не клиент), но планка минимализма.
4. **Clash Verge Rev** — таблица скриншотов dark/light (компактнее, чем details-блок), строка языков (8 языков) в шапке.
5. **Hiddify** — GIF-демо вместо статичного скриншота (цепляет сильнее); один абзац «what is» без слогана.

## Что раздражает (не брать)

1. **Clash Verge Rev: Promotion-блок** — реклама сторонних VPN-провайдеров и AI-сервиса в README открытого клиента. Для проекта, претендующего на доверие, это красный флаг. У sora такого нет — и не должно появляться.
2. **Дублирование каждого абзаца на 2 языках** (v2rayNG, Clash Verge Rev, Nekoray) — файл раздувается вдвое, читать невозможно. Текущее решение sora (два отдельных файла) — правильное, сохранить.
3. **Донаты с криптокошельками в README** (Amnezia, Nekoray) — визуальный мусор.
4. **Стены бейджей и contrib.rocks** (Hiddify) — шум, ноль информации.
5. **Инструкции по сборке в README** (Amnezia, ~150 строк) — это контент для CONTRIBUTING/development.md.
6. **Nekoray** — весь README фактически на китайском; плюс проект заброшен (архив, «不再维护»). Как референс структуры — слабый.
7. **v2rayNG** — крайность в другую сторону: ноль списка возможностей, ноль скриншота. Новому пользователю непонятно, зачем это ему.

## Сравнение с текущим README sora

**Что у нас уже лучше конкурентов:**
- Установка одной командой для Win/Linux — ни у кого из шести нет такого в README.
- Честная первая строка («для тех, у кого есть подписка») — только у Hiddify есть аналог.
- Отдельные RU/EN файлы вместо дублей внутри одного.
- Структурированный индекс документации в репозитории.
- Ноль мусора: нет донатов, рекламы, стен бейджей.

**Что хуже / чего не хватает до «лучший в мире»:**
1. Нет одной строки-дифференциатора: прочитав README, непонятно, чем sora отличается от Hiddify. Уникальное (DPI-фрагментация, REALITY/XHTTP/AmneziaWG/Hysteria2 из коробки, zapret-режим на Linux, диагностика HAR/PCAPNG/EVTX, расширения) растворено в 8 длинных пунктах.
2. Раздел «Что умеет» — 8 пунктов без приоритета; «31 язык и темы» в одном пункте с треем и автообновлениями. Глаз не цепляется ни за что.
3. Нет сигнала «проект живой»: ни бейджа релиза, ни версии. У конкурентов бейджи (пусть и с шумом) этот сигнал дают.
4. Нет быстрого старта после установки (вставить ссылку → выбрать сервер → подключить). Установка есть, а «что дальше» — нет.
5. Нет строки доверия: подпись релизов/проверка контрольных сумм упомянута вскользь в установке, но не выделена.
6. Строка про sora-legacy в разделе возможностей — это не возможность sora; навигационный мусор в неположенном месте.
7. Расширения (новый раздел, конкурентное преимущество) в README не упомянуты вообще.

## Требования к новому README (утверждено аналитиком)

- Структура: шапка (1–2 строки сути + кому) → скриншот → установка (2 команды) → быстрый старт (3 шага) → возможности (6 коротких приоритетных пунктов) → документация → лицензия.
- Один бейдж: latest release. Больше никаких бейджей.
- Возможности — только то, что отличает или решает: протоколы/DPI, движки, подписки, маршрутизация+kill switch, zapret, диагностика, расширения. Без «31 язык» отдельным пунктом (упомянуть вскользь), без трея/тем как «возможностей».
- Быстрый старт: 3 шага, без скриншотов.
- sora-legacy: убрать из README (на усмотрение владельца — одной строкой в docs/install.md).
- Не добавлять: донаты, contributors, tech stack, инструкции сборки, community-ссылки (их нет — не выдумывать).
- Черновики: `README.draft.md` (RU), `README.en.draft.md` (EN) — в этом же каталоге.
