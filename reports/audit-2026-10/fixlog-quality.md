# Лог контроля качества (Раунд 3)

Придирчивый ревью всех `[audit-fix]`-коммитов: 47 в sora, 28 в sora-legacy.
Формат: коммит — вердикт — 1–2 строки.

## sora — High (глубокая проверка, все 8)

- `31f9008` (H1, minisign) — **ок**. Fail-closed на плейсхолдере ключа, проверка до доверия
  хэшам, убран `--allow-unsigned-rpm`. Сообщения понятные.
- `4c2bcb9` (H2, polkit/authz) — **ок**. Матрица read/control аккуратная, unknown-методы
  fail-closed. Регрессия e2e-теста чинена отдельным r3-коммитом `f0b45cb`.
- `48e265a` (H3, ExportDiagnostics) — **ок**. Сырые форматы убраны, docstring честный.
- `3089f3c` (H4, kill switch root) — **ок**. Fail-closed с понятным сообщением;
  ошибка пробрасывается наверх, пользователь видит причину, а не тихую утечку.
- `9da448a` (H5, digest движков) — **ок**. PATH-fallback убран, `checkDigest` fail-closed,
  env-override за флагом `--allow-env-bin`.
- `6b8792f` (H6, journal race) — **ок**. Канал больше не закрывается; проверен единственный
  потребитель `session.Journal` (WatchEvents через select+ctx — зависания нет).
  `engine.EventBus` не затронут (там закрытия и не было проблемы).
- `b763d2e` (H7, StopGrace) — **ок**. Дефолт 3s при `StopGrace<=0` проверен (manager.go,
  runner.go) — нулевого таймаута быть не может.
- `e0062ec` (H8/L27/L28/L29, Dart+C++) — **ок**. Сигнатуры vfunc, `transfer full/none`,
  очистка в dispose — всё корректно; Dart-дедуп 5s, `exec "$2"` в кавычках.

## sora — Medium/Low (выборочно: M1, M2, M11, M12 + Dart)

- `5c764b2` (M1, cap соединений) — **ок** с замечанием: дедлайн в `dispatch` действует только
  на тестовый `Serve`-путь; продовая защита — cap 128 + keepalive 10 мин. Достаточно.
- `fde323b` (M2, argv для ip) — **ок**. Валидация имени интерфейса + векторы, шелла нет.
- `3560926` (M11, debounce) — **ок**. Пустой probe сбрасывает pending; wake-from-sleep
  сразу (путь точно мёртв).
- `dea6531` (M12, Start/Stop) — **ок**. `stopping` под мьютексом; Stop на свежей сессии
  не отравляет её.
- `beaa8b3`, `2f39f36`, `ac8fbba` (Dart) — **ок**. `_connectQueued` корректно потребляется;
  `_known` синхронизирован во всех путях; `catchError` для истории — осознанно.
- `0b295ca` (R2 NEW-1) — **ИСПРАВЛЕНО мной**: `exec.LookPath` использует PATH, так что
  «защита от подмены через PATH» была мнимой. Заменено на резолв из фиксированных
  системных каталогов (`/usr/sbin`, `/sbin`, `/usr/bin`, `/bin`) + fail-closed.
  Коммит `e67a005` (sora), тесты переведены на хуки (`NftBinForTest`, `ipBinForTest`).
- `41f013a` (R2, доки L8/L18) — **ок**.

## sora-legacy — High/ключевое (выборочно)

- `e31f0fc` (H1, C# верификация) — **ок**. Fail-closed при несовпадении хэша, downgrade
  запрещён числовым сравнением версий. Замечание: `.dgst` берётся с того же релиза
  (TLS-only) — честно задокументировано как кодовая часть, подпись — за владельцем.
- `1e6ef47` (H2, runas) — **ок**. Подтверждение при user-writable каталоге, текст диалога
  понятный, без жаргона.
- `ae3b541` (H3, Edit/whitelist) — **ок**. Whitelist расширений + notepad без
  UseShellExecute + защита от path traversal.
- `fb7cf2a` (H5, Go) — **ок**. Аналогично sora.
- `38074e0` (M2, session ID) — **ок**. Тест обновлён корректно.
- `cadb40b` (M6, deadline) — **ок**.
- `d8e814d`, `0fedd1a` (R2 NEW) — **ок**. HttpClient в using, метрики мимо прокси.
- `f015417` (мой quality-коммит) — legacy tunroute переведён на `resolveSystemBin`,
  как в sora.

## UI/UX-проход (Flutter, sora/app)

Проверено: показ ошибок, состояния экранов, локализация, дёргание.

- **Сырые ошибки в UI: не найдено.** Ошибки идут через каталог `CoreFailure` →
  `describe()` в kit.dart → локализованные строки (`S.of(context)`). Красного
  хардкоженного стиля нет. `speedtest` показывает только локализованные тексты.
- **Хардкоженные строки: не найдено** (кроме бренда «Sora»).
- **Состояния loading/error/empty: есть везде** (лицензии, серверы, speedtest, логи).
- **Overflow: обработан** (`maxLines` + `ellipsis` в Tile, _ServerRow).
- **Дёргание: устранено ранее** (M18 — O(1) дедуп логов, M20 — троттлинг probe,
  AnimatedSwitcher на главном экране).
- Вердикт: **исправлений не потребовалось** — UI уже на уровне «топового», правки
  раундов 1–2 (H8 диплинки, M18/M19/M20) аккуратные.
