## Что поддерживает sora (закрытый перечень)

По первоисточникам организации OpenLibreCommunity протокол у сообщества один — **olcRTC** (WebRTC через SFU видео-звонков). olcng — клиент (форк v2rayNG), не протокол; собственных форматов ссылок у него нет. Поддержаны: **URI v1** и **формат подписки v1** (docs/uri.md, docs/sub.md сообщества).

Грамматика: `olcrtc://<Provider>?<Transport>[<k=v&k=v>]@<RoomID>#<Ключ-64hex>$<Имя>`. Провайдеры: jitsi / telemost / wbstream (+ `none` — не выражается ссылкой). Транспорты: datachannel / vp8channel / seichannel / videochannel, полный словарь параметров — SPEC.md §3. Wire: OLC2 (HKDF-SHA256 из PSK → XChaCha20-Poly1305, smux, handshake v3). Референсный клиент сообщества (owenclave) дефектен — молча теряет параметры `<...>` и не реализует подписку по спеке; sora делает по спеке, дефекты референса не скопированы (SPEC.md §6, 10 расхождений док↔код зафиксированы).

## Interop (INTEROP.md) — честный объём среды

Сквозной трафик через внешний SFU в этой песочнице **физически невозможен**, по трём независимо измеренным свойствам среды (не дефекты sora/olcrtc): эгресс-прокси зависает на POST и WebSocket-Upgrade (сигналинг jitsi/wbstream мёртв); ядро запрещает UDP, включая loopback (WebRTC-медиа невозможно); прямой эгресс перехватывается (TLS ломается).

Доказано фактически:
- Туннельный стек пина несёт трафик: upstream e2e-набор на исходниках тега v0.0.1 — SOCKS→handshake→crypto→srv-эхо PASS, **32 МиБ байт-в-байт**, реконнекты/failover PASS.
- Локальный LiveKit (провайдер none): сигналинг ✅, srv+cnc в одной комнате по логам SFU для всех 4 транспортов; медиа упёрлось в ICE/UDP среды.
- Sora вживую: настоящий core + импорт ссылки → план, digest-ворота, рендер YAML (комната/ключ дословно, DNS из плана), запуск сайдкара; Connect честно упал на join за 137–275 мс (fail-closed, FAILED) — сайдкар под ядром идёт без прокси по `supervise.SafeEnv()` (by design), а прямой эгресс в песочнице перехвачен.
- Негативы вживую: подменённый сайдкар → `binary_missing` за 13 мс, 0 процессов; `token_required` за 9 мс; `not_connectable`/`combination_unsupported`; мёртвая комната верифицирована разными комнатами в логе SFU.
- Рестарт из vault без повторного импорта ✅ (YAML после нормализации эфемерных полей байт-идентичен первому запуску).

**Остаток на dev-машину** (команды готовы, INTEROP.md §7/§9): сквозной трафик через живой SFU (jitsi/telemost/wbstream), время join до готовности слушателя и пропускная на живом провайдере, неверный ключ (среда режет раньше handshake — стадию не различить), wbstream с модераторским токеном, TUN-целиком, Windows-бинарь WebRTC.
