## 3. Стандарт адаптивной ОС-интеграции (критерий приёмки отдела) — что сделано

- **Версии Windows Win7→Win11 — capability checks, не предположения:**
  активация окна — только API со времён XP (IsWindow/ShowWindow/
  SwitchToThisWindow); восстановление прокси — реестр + wininet (есть на
  всех целевых ОС), без внешних бинарей; DPI — манифест PerMonitorV2 на
  Win10 1703+, system-aware (dpiAware true/PM) на Win7/8: одна сборка,
  поведение выбирает загрузчик ОС; SetProcessDPIAware удалён именно
  потому, что при манифесте он бесполезен на каждой версии.
- **Автозапуск:** реестровый контракт байт-в-байт эталону
  (`SoraAutoRun_<MD5(StartupPath)>` = `"<exe>" --silent`), Reconcile
  усыновляет/переписывает значение на текущий exe; UI-тогл читает реестр,
  а не настройку, и при расхождении откатывается к факту, не закрывая диалог.
- **Трей:** единственный владелец — MainForm; состояния различимы формой
  глифа (не только цветом) и подписаны локализованным tooltip; balloon —
  только на значимых переходах; потеря ядра честно показывает errCore,
  а не «Connected».
- **Ассоциации ссылок:** регистрация sora:// per-user (HKCU при
  lowest-privileges), корректное квотирование "%1", снятие при
  деинсталляции; импорт — обе формы эталона, передача работающему
  экземпляру, routing-форма честно отклоняется (в ядре её нет).
- **Деинсталляция:** --restore-proxy возвращает PAC/прокси/байпас по
  записанному user-wininet.json (числовая форма флагов — по эталонному
  PerConnFlags); задекларированные ограничения: бит AUTO_DETECT живёт
  только в бинарном DefaultConnectionSettings и не восстанавливается,
  RAS-подключения реестровым replay не переигрываются (обе частичности
  написаны в коде и документации, а не умолчаны).
- **Ограничения системы — понятные состояния, ноль сырого текста:**
  глобальные обработчики исключений (в лог — только имя типа); все
  пользовательские тексты нового кода — только ARB-ключи (пин:
  одинаковые множества ключей в 31 локали + все ключи кода существуют).

## 4. Чек-лист мелочей — что сделано

- **Табуляция/фокус:** явных TabIndex было 0 во всём Client — спроектированы
  на всех формах; деструктивное удаление — фокус и дефолт на «Отмена»
  (Enter не удаляет); начальный фокус диалогов осмыслен (Add — ввод,
  Modes — активный режим).
- **Мнемоники:** было 0 — хелпер Mnemonic.Mark: буква из реально
  присутствующих в локализованном тексте, один used-набор на поверхность
  (дублей нет по построению), локаль без кандидата — без мнемоники;
  готовый '&' в тексте не двоится (гарантия перенесена из данных в код);
  AntdUI-кнопкам мнемоники сознательно не ставятся (поддержка '&'
  неверифицируема без Windows-рантайма) — компенсация TabIndex + Accept/Cancel.
- **Выравнивание/сетка:** диалог Add переведён с голых координат на якоря;
  AutoScaleMode.Dpi у диалогов; шрифты px→pt (те же размеры на 96 DPI).
- **Тексты/терминология:** глоссарий Client сверен с sora (273/274 общих
  ключей); расхождение engine=«Ядро»/errCore=«Служба» ревьюером
  подтверждено как байт-в-байт паритет с sora-ARB, не legacy-дрейф.
- **Длинные имена/пути:** EndEllipsis + ToolTip на месте; карточкам даны
  AccessibleName (проверка screen reader — dev-машина, §7).
- **DPI 100–200%:** манифест + AutoScaleMode + pt-шрифты + якоря (§3).
- **Имена/комментарии:** за время подъёма ревьюерами сняты все найденные
  «комментарии врут коду» (Sora.iss, SystemProxy, ClientSettings,
  resolveImportedSpec — последний теперь запинен тестом на семантику);
  контрактные константы сведены в ClientContract.
