## Топ критичных (через все прогоны)

1. **Staged update был мёртв на 100%** (№9). `updates.dart` скачивал `SHA256SUMS`, но не `SHA256SUMS.minisig` — helper без подписи отказывался работать. Подтверждено эмпирическим прогоном настоящего `sora-update`. **Исправлено** (`ae750a9`) + фикстура CI-теста (`492aa2d`) + честная ручная процедура подписи в release job (`73d845d`).
2. **Dart `BenchmarkServersRequest` — сдвинутые wire-теги** (№4). Hand-written стаб пропустил поля — app слал `server_ids` на теге `request_id`. Бенчмарки F2 были мертвы на проводе. **Исправлено**, сверено байт-в-байт с Go-дескриптором; добавлен тест `TestNewFieldTagsAreStable`.
3. **Dart заявлял API 1.8 при ядре 1.10** (№4). Negotiation упирался в 1.8, гейт `link.minor >= 10` безусловно отключал chains (F8) и zapret-with-VPN (F11). **Исправлено** бампом до 1.10.
4. **F9 sync UI — театр безопасности** (№1 H1, подтверждён №10). Экран обещает «E2E encrypted sync», но QR-токен Go-демон не видит, «пейринг» = запись в локальный реестр, HTTP API демона приложением не вызывается; QR-форматы Dart и Go несовместимы. **Требует продуктового решения**: реальная проводка или убрать фейк. Мелкий фикс был бы слопом — не делали.
5. **У панелей расширений не заблокирован `fetch`** (№1 H2). Док обещает «no network from JS in v1», код режет только навигацию — вредоносное расширение с `connections.read` эксфильтрует данные одним запросом. **Спека**: CSP `connect-src 'none'` с loopback-сервера (Dart).
6. **`strings_zh.dart` не компилировался** (№7). 88 нереализованных абстрактных членов — предсуществующий баг волн. **Исправлено**.
7. **Утечка engine-процессов и горутин в `bandwidth.go`** (№6). Продюсеры висли навсегда при обрыве gRPC-стрима, `eng.Close()` не выполнялся. Воспроизведено тестом. **Исправлено** (ctx-aware send).
8. **mDNS-spoof → демон синка звонил на WAN** (№1 M2). **Исправлено** LAN-гейтом.

## Что исправлено (18 коммитов)

- Безопасность: `WatchExtensionEvents` больше не отдаёт journal Detail токенам без прав; капы handshake на LAN-слушателях; LAN-гейт для dial; очистка недописанного `id@version`.
- Флоу: префилл `sora://`-ссылок из буфера; честный «paired» только при реальном добавлении; rollback/uninstall расширений больше не молчат; ошибка сохранения настроек расширений видна; ошибка подключения цепочки не подавляется.
- Perf: Expando-кэш группировки серверов; троттлинг записи `history.json` ≤1/30с + `sort.SliceStable`; разбор query один раз на ссылку.
- Контракты: фикс wire-тегов, бамп API 1.10, пин тегов тестом.
- Ошибки: 3 проглоченные исправлены (реестр пиров синка, wireguard-ключ, `_ = g` в ext/host).
- Конкурентность: 2 фикса (выше).
- i18n: plural `connConnectionsCount`, zh-классы, `NumberFormat` с локалью вместо `toStringAsFixed`, RTL-фиксы.
- a11y: `Pressable.semanticButton`, `Tile` button/selected, `Semantics(checked:)` на чекбоксе опасных прав, `ExcludeSemantics` на декоративном, `minHeight` вместо фикс-высот.
- Упаковка: minisig в staged updates, фикстура helper-теста, кап скачивания `.soraext`, ручная процедура подписи в workflow.
- Доки: честный статус F9, `APP_VERSION` в релизных доках, фиксы extensions-доков.

## Осталось

**Решения владельца:**
- F9: реальная проводка синка (упаковать демон, API-клиент в app, единый QR-формат) или скрыть экран. Сейчас — витрина.
- Контраст `danger` на светлой теме 4.34 < 4.5 (a11y) — кандидат `#D92D20` (4.83), но цвет брендовый.
- `APP_VERSION` в CI релизов (`repository.yml`) — сейчас гейт `min_app_version` молча пропускается.
- Key ceremony minisign (известно ранее).

**Cross-ref / спеки (не чинили — чужой угол или нужен стенд):**
- `sora.dart:1293`: удаление выбранной подписки оставляет висячий `settings.server` → мёртвый `proxyTarget` (единственное настоящее битое состояние из флоу-прогона).
- CSP `connect-src 'none'` для панелей расширений (Dart).
- `catalog`: сверка `entry.authorKey` (сейчас только sha256 + self-attested ключ).
- Zip-бомба в Dart-распаковке `.soraext`.
- `ProfileMatched` молча дропается в `_watchSession` (Dart).
- ~25 unary gRPC без таймаута → вечный спиннер при зависшем ядре (рекомендован центральный дефолт-таймаут).
- `core/ext.Store.Rollback` не перечитывает манифест N-1 (код пока недостижим — править мёртвый код = слоп).
- zypper `--allow-unsigned-rpm`: нужен стенд openSUSE.

**Dev-машина:** `flutter analyze` + build (Dart без SDK), `buf generate` для Dart-protobuf вместо hand-written стабов, сборка C#.

## Фильтр слопа — что отсеяно (честно)

- Машинный перевод 214 ключей × 29 языков (фейковое качество; EN-fallback лучше).
- Дописывание 8 RPC + 20 сообщений в Dart вручную (риск повторения wire-бага №2; правильный путь — `buf generate`).
- Кэширование счётчиков соединений (несвежие данные хуже честного опроса).
- Confirm'ы на очистку логов/удаление правил (шум ради эфемерного).
- Сужение granted-прав при откате расширений (инертно: bridge гейтит по паре метод→право).
- 7 «оптимизаций» (кольцевой буфер журнала, ручные суррогаты и т.д.) — правит шум, не проблему.
- Видимые кнопки reorder для скринридера (шум; правильно — `customSemanticsActions`, ждёт 2 строк l10n).
