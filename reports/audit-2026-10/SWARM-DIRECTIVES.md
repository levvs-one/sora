## КРИТИЧЕСКОЕ УТОЧНЕНИЕ: как коммитить выборочно (2026-10-20 ~00:45, лид)
`git commit -m ... -- <paths>` ИГНОРИРУЕТ индекс и пишет ТЕКУЩЕЕ СОДЕРЖИМОЕ
файлов из рабочего дерева! Для чужого стейджа в других файлах это безопасно,
но для грязного файла pathspec-форма подхватит ВСЕ незакоммиченные ханки
файла, включая чужие (инцидент `45fec12`: в мой коммит попали 2 чужих ханка
`sora.dart` @@ -476 и @@ -1966 — работа detail-fix отдела, продолжена ими же
в `b2e8d62`; мой ханк цел, дерево консистентно, но атрибуция в `45fec12`
неверная — чинить финальным проходом).
Правильная процедура для выборочного коммита грязного файла:
  1. `git diff -- <file> > /tmp/full.patch`, вырезать нужные ханки в /tmp/want.patch
  2. `export GIT_INDEX_FILE=/tmp/idx-$AGENT && git read-tree HEAD`
  3. `git apply --cached /tmp/want.patch` (проверить `git diff --cached --stat`)
  4. `git commit -m "..."` (без pathspec! возьмётся временный индекс)
  5. `unset GIT_INDEX_FILE`
Запрещено: полагаться на pathspec для грязных файлов; `git commit -a`;
коммитить файл без `git diff HEAD -- <file>` перед этим.
