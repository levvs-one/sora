# 09. QUIC как транспорт — SNI slicing, 0-RTT, migration; новое в Xray ≥25.6.8 / sing-box ≥1.12 / Hysteria ≥2.6.2

Дата: 2026-10-20. Источники: RFC 9000 (§7 0-RTT, §9 connection migration), USENIX Security 2025 (GFW парсит QUIC Initial), FOCI 2026 (RU QUIC SNI-цензура), Hysteria changelog 2.6.2, sing-box changelog 1.12, Xray-core (apernet/quic-go, удаление standalone QUIC-транспорта).

## База: что даёт QUIC транспорту (RFC 9000)

- **0-RTT:** клиент с ранее установленной сессией шлёт шифрованные application data в первом же пакете (нужен session ticket / PSK от прошлого соединения). Выигрыш — до 1 RTT на переподключение. Цена — риск реплея (протокол гарантирует идемпотентность на уровне приложения; для прокси-транспорта ок).
- **Connection migration (§9):** сессия переживает смену IP (Wi-Fi ↔ LTE) благодаря Connection ID — критично для мобильных. TCP-транспорты при смене сети рвутся и переподключаются.
- **Мультиплексирование без HoL:** независимые стримы; потеря пакета в одном не стопает остальные (в отличие от TCP).
- **Шифрование хендшейка:** TLS 1.3 встроен в QUIC; Initial-пакеты шифруются деривированным ключом — но **SNI извлекаем** (ниже).

## QUIC SNI: атака и защита

**Атака (подтверждено):** USENIX Security 2025 — GFW расшифровывает QUIC Initial на лету (DCID + salt) и извлекает SNI из ClientHello; блок по триплету (src IP, dst IP, dst port) на 180 секунд. **Один Initial-пакет достаточен** (против минимум 2 пакетов для TCP TLS). FOCI 2026 — аналогичная QUIC SNI-цензура зафиксирована в RU (Москва, СПб, Новосибирск).

**Защита — фрагментация/SNI slicing:**
- **Hysteria 2.6.2 (подтверждено changelog):** «ClientHello is now fragmented during TLS handshake, which can bypass some firewalls' SNI filtering» + quic-go v0.52.0. Механика: ClientHello режется на несколько QUIC-пакетов так, что ни один пакет целиком не содержит SNI — парсер цензора, ждущий SNI в одном Initial, не срабатывает.
- **sing-box 1.12 (подтверждено changelog):** Hysteria2-клиент по умолчанию **пародирует QUIC-хендшейк Chrome** (handshake fingerprinting), опция `disable_chrome_parrot`; новые типы QUIC-обфускации `gecko` (рядом с `salamander`) с настраиваемым `min/max_packet_size`; `bbr_profile`, `hop_interval_max`.
- **Xray ≥25.6.8:** в prior research (WEB-RESEARCH тир S #1) утверждается QUIC SNI slicing по умолчанию; **независимый первоисточник в этом проходе не найден** — помечаю как «требует верификации по релиз-ноутам», а не как факт. (Подтверждено другое: Xray использует форк `apernet/quic-go` v0.61.1 и **полностью удалил standalone QUIC-транспорт** — `infra/conf/transport_internet.go`: миграция на XHTTP stream-one + H3.)

**Важно:** фрагментация — гонка вооружений. Цензор может научиться реассемблировать; на 10.2026 работает против GFW/ТСПУ, гарантий на будущее нет.

## Что нового по движкам (сводно)

| Движок | Версия | QUIC-новое (подтверждено) |
|---|---|---|
| Hysteria | ≥2.6.2 | Фрагментация ClientHello (anti-SNI), quic-go v0.52.0; 2.6.4 — quic-go v0.54.0, фикс пиннинга сертов; 2.6.5+ — quic-go v0.57.1, фикс BBR |
| sing-box | ≥1.12 | Chrome-parrot QUIC-хендшейка hy2-клиента по дефолту, `gecko`/`salamander` обфускация, `bbr_profile`, `hop_interval_max` |
| Xray | ≥25.6.8 | SNI slicing — **не верифицировано** в этом проходе; точно: удаление QUIC-транспорта → XHTTP/H3, свежий quic-go форк |

## Вердикт: лучшее (свежесть движков = фича)

QUIC-транспорт (Hysteria2/TUIC/XHTTP-H3) — ключевой ответ на троттлинг TCP и QUIC-цензуру 2026. Фрагментация ClientHello и Chrome-parrot — реальные, подтверждённые changelog'ами контрмеры. Главной «фичей» является **свежесть движка**: sora получает всё это бесплатно, держа пины актуальными.

**Отсеяно фильтром:** «QUIC = невидимость» — опровергнуто USENIX 2025 и FOCI 2026; «SNI slicing в Xray 25.6.8» без первоисточника — не факт, а кандидат (помечено выше).

## Внедрить в sora так

1. **Пины движков:** Hysteria ≥2.6.2 (лучше ≥2.6.5 — фикс BBR и memory leak), sing-box ≥1.12, Xray — свежий (проверить релиз-ноуты на предмет QUIC SNI slicing и зафиксировать версию, где подтверждено). Это P0 — «бесплатные» антицензурные улучшения.
2. **sing-box hy2:** прокинуть `disable_chrome_parrot` (дефолт false — parrot включён; отключать только при Ed25519-сертификатах сервера — в UI предупреждение), типы обфускации (`salamander`/`gecko`) + `min/max_packet_size` в advanced.
3. **QUIC-префлайт:** в диагностике — тест «UDP/443 проходит? QUIC Initial с SNI блокируется?» (канареечный QUIC-хендшейк к своему серверу) → рекомендация транспорта: QUIC-домен работает → hy2/TUIC; нет → XHTTP/REALITY-TCP.
4. **Мобильный сценарий:** connection migration — аргумент за hy2/TUIC как дефолт на Android (смена Wi-Fi/LTE без разрыва); в UI пометить «переживает смену сети».
5. **0-RTT:** включается на уровне quic-go автоматически при резюме сессии; отдельных действий не требует — но в UI не обещать «0-RTT всегда» (только при повторных подключениях).
6. **Убрать QUIC-транспорт Xray из UI** (движок его удалил — см. тему 10).
7. **Не делать:** собственный QUIC-стек; ручную реализацию фрагментации (это в quic-go форках движков).
