## 2. No-logs: факты, не маркетинг

- **Cloudflare — единственный с независимым аудитом среди бесплатных:** KPMG, последний — апрель 2026: retention 25 часов, полные IP не пишутся на диск. Отчёт по запросу (не публичный полностью) — честная оговорка. Юрисдикция США, бэкенд закрыт.
- **Quad9:** швейцарский non-profit; IP-источника не логирует; ECS не шлёт вообще; malware-blocking по умолчанию (threat intel от партнёров). Независимого аудита уровня KPMG в открытых источниках 2026 не найдено — заявление фонда, не проверенный факт.
- **AdGuard:** операционные логи 24ч (заявлено); фильтрация рекламы/трекеров — их дифференциатор.
- **Google:** временные логи 24–48ч, затем анонимизация (заявлено).
- **NextDNS/Control D:** логи настраивает пользователь (отключаемые) — честнее всех по контролю, но требует аккаунта.

**Правило для UI sora:** пометку «no-logs» ставить только с указанием основания: «аудит KPMG 04.2026» (Cloudflare), «заявление оператора» (остальные). Иначе — тот же маркетинг, что у скам-VPN.

## 3. Скорость (замер TechUpsider, октябрь 2026, Джакарта — как пример методологии)

Медиана UDP: CF 9.3ms / 8.8.8.8 9.1ms (popular); random-имена: 8.8.8.8 22.1ms, CF 25ms, Quad9 35.5ms, AdGuard 101.9ms. Вывод не «кто быстрее», а: **скорость региональна** — дефолт должен выбираться замером (transport probing из 32), а не глобальным рейтингом.

## 4. Фильтрация (замер ispreview, сентябрь 2026, 100 сэмплов)

Malware-block: Quad9 100%, AdGuard 100%, CF 96%, NextDNS 94%. Phishing: CF 74%, AdGuard 72%, NextDNS 46%, Quad9 36%. Для RU-пресета: AdGuard/Comss — лучший баланс «антифишинг + скорость в регионе».

## 5. Рекомендуемый набор sora (2026)

**Дефолт (авто):** Quad9 h3 → AdGuard h3 → Cloudflare h3, probing при старте.
**RU-антицензурный:** AdGuard h3 (или Comss DNS) → Quad9 h3 → Cloudflare h3; `.ru` — direct.
**Чистые сети / скорость:** Cloudflare h3 первым.
**Убрать:** Mullvad (закрытие 02.11.2026).
**Не добавлять:** «свои» резолверы sora (операционная нагрузка + единая точка доверия — из прохода 1, подтверждено).

ECS: не включать нигде по умолчанию. DNSSEC: валидация на стороне резолвера есть у всех пяти; локальную валидацию не требовать (ломает кривые зоны).

## Вердикт: лучшее

Аудит с датами и основаниями заявлений — лучшее: единственная защита от «no-logs»-маркетинга. Слоп — таблица «все поддерживают всё» без дат и без различия «аудит vs заявление».
