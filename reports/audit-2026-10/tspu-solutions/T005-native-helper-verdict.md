# T005 — нативный UDP-хелпер: вердикт прохода PASS1 (2026-10-20)

## Вопрос

`QueueAllocator` (core/desync) внедрён в прошлых раундах с честным
NOT WIRED: очередь пакетов для UDP-десинка есть, но нет нативного
per-OS хелпера, который бы эту очередь наполнял. Можно ли честно
закрыть в этом проходе?

## Вердикт: НЕ реализуемо честно в этом проходе. NOT WIRED остаётся.

Причины — не «не успели», а структурные:

1. **Linux (NFQUEUE)** требует root/CAP_NET_ADMIN и модификации
   netfilter-правил хоста. Клиент sora работает без привилегий;
   helper-демон с повышением прав — это отдельный компонент уровня
   установки (polkit/systemd unit, подпись, аудит безопасности), а не
   проход по коду.
2. **Windows (WinDivert)** требует подписанного драйвера
   (Attestation/EV-подпись) — та же церемония подписи, что уже числится
   открытым действием владельца для релизов. Без подписи драйвер не
   встанет на пользовательской машине.
3. **Верификация невозможна здесь**: в песочнице нет ни CAP_NET_ADMIN,
   ни Windows-хоста; код хелпера нельзя ни запустить, ни честно
   протестировать. Непроверяемый привилегированный код — слоп по
   определению задачи.
4. **Приоритет упал по данным T049**: главный потребитель UDP-десинка —
   QUIC ClientHello — уже фрагментируется upstream quic-go во всех
   трёх движках (см. аддендум в `31-quic-residual-ban.md`). Нативный
   десинк остаётся нужен для не-QUIC UDP и TCP-десинка уровня zapret,
   но это уже не блокер QUIC-пути.

## Что нужно для закрытия (чек-лист владельцу)

- [ ] Решение по модели привилегий: helper-демон (Linux) и служба
  (Windows) как отдельные подписанные артефакты релиза.
- [ ] Подпись WinDivert-драйвера (та же церемония, что Authenticode
  для инсталляторов — уже в списке действий владельца).
- [ ] Полевой стенд: машина с CAP_NET_ADMIN + RU-вантаж для замера
  эффекта NFQUEUE-десинка против ТСПУ (T026 pcap-harness).
- [ ] После этого: `QueueAllocator` получает прод-вызывающего, маркер
  NOT WIRED снимается коммитом с тестами на реальном железе.

До выполнения чек-листа статус: **QueueAllocator — NOT WIRED,
причина: нет привилегированного нативного хелпера; QUIC-путь при этом
не блокирован (upstream-фрагментация, T049).**
