# T010 — DNS-защита: рантайм-детект перехвата, запрет тихого даунгрейда, DoH по IP-литералу, racing, DNS внутри туннеля

## Проблема
РКН/ТСПУ перехватывает и подменяет DNS: DNAT-перехват UDP/53 на 8.8.8.8/1.1.1.1 с
ответом от NSDI (195.208.5.1), удаление записей из NSDI (youtube.com, WhatsApp —
02.2026), маркер цензора 188.186.146.208. DoT мёртв (блокировка 853/TCP), DoH к
Google/Cloudflare висит (SNI-blackhole). SNI-обход без DNS-обхода бесполезен:
клиент резолвит через отравленный DNS и идёт не туда.

## Что уже сделано (коммит)
`fe048b5` — `core/diagnostics/dnsintercept.go`: рантайм-зонд перехвата DNS.
Детекторы: NXDOMAIN **с aa-флагом** (рекурсивный резолвер никогда не отвечает
авторитетно), расхождение UDP/TCP-ответов, IP-маркеры цензора, сравнение с
контрольным резолвером. Бюджеты 3с, hand-rolled DNS wire codec (stdlib only).
Вердикт: `Intercepted / Spoofed / Clean / Unknown`.

## Решение (остаток работы)

### 1. DNS внутри туннеля — дефолт, не опция
- Весь DNS-трафик клиента идёт через TUN в зашифрованном виде (уже так: sing-box
  всегда prepends `hijack-dns` route rule; `defaultTunResolvers` =
  `https://1.1.1.1`, `https://8.8.8.8` — IP-литералы, без SNI).
- Исключение — только bootstrap: резолв IP самого DoH-сервера, если он задан
  доменом. Bootstrap идёт через системный DNS один раз при старте, результат
  кэшируется и пинится.
- **Запрет тихого даунгрейда**: падение зашифрованного DNS НЕ ведёт к
  прозрачному fallback на plain UDP/53. Состояния: зашифрованный DNS работает /
  деградировал (UX-баннер + повтор) / недоступен (блок подключения, не тихий
  plain). P15-4 (split-DNS для .ru) — только явной опцией пользователя, по
  умолчанию выкл: split-DNS — это дыра для отравления.

### 2. DoH по IP-литералу + racing + короткие таймауты
- DoH-эндпоинты хранить как IP-литералы (`https://1.1.1.1/dns-query`), обходя
  SNI-фильтр. У Cloudflare есть IP SANs в серте — валидация проходит.
- Racing: параллельные запросы к 2–3 резолверам, побеждает первый валидный
  ответ; таймаут на попытку 2–4с (DoH к заблокированным SNI виснет, а не
  отвечает RST).
- Порядок: DoH → (опционально) DoH3 → отказ. DoT не предлагать (порт мёртв).
  **DoH3 — opt-in, не дефолт** (P15-8): без полевых замеров стабильности
  h3-транспорта в ТСПУ делать его дефолтом нельзя.

### 3. Зонд перехвата в пайплайне подключения
- `dnsintercept.go` вызывается при каждом (пере)подключении и по кнопке
  «Проверить DNS» в диагностике. Вердикт `Intercepted/Spoofed` → баннер
  «ваш DNS перехватывается», рекомендация: сменить сеть / включить DNS внутри
  туннеля (если был выключен) / сменить резолвер.
- Вердикт пишется в журнал сессии (для матрицы ТСПУ).

### 4. RU-пресет резолверов
- Пресет «RU-антицензурный»: Comss (`https://dns.comss.one/dns-query`,
  `https://router.comss.one/dns-query`, bootstrap 195.133.25.16/212.109.195.93),
  Quad9, Cloudflare-by-IP, Google-by-IP. Проверено 2026-10-20: оба Comss-URL
  отвечают (HTTP 400 на GET = живой AdGuard-совместимый эндпоинт).
- Выбор резолвера — racing между пресетом, а не статичный primary/secondary.

## Сложность
Средняя. Зонд готов. Остаток: bootstrap-пиннинг (~150 строк Go), racing
(~100 строк), UI-переключатель DNS + leak-тест (Dart, спека ниже в UI-части),
пресет (~50 строк конфига).

## Эффект
Закрывает самый дешёвый вектор ТСПУ. Без этого любые обходы SNI/потоков
бессмысленны — клиент ходит по отравленным адресам.

## Риски
- DoH по IP ломается при смене IP резолвера (нужен bootstrap-обновлятор).
- Racing утраивает DNS-нагрузку (приемлемо: DNS — копейки трафика).
- Жёсткий запрет даунгрейда = в сетях с белым списком DNS (корпоративные,
  отели) клиент не подключится вообще. Митигация: детект captive portal
  (отдельная задача) с явным согласием пользователя на временный plain DNS.

## Честные ограничения
- Зонд детектит перехват, но не отличает «провайдерский прозрачный прокси»
  от «ТСПУ-инъекции» — вердикт `Intercepted` честно покрывает оба.
- Одиночный прогон зонда — не диагноз: нужен повтор (2 из 3).
- DoH3 остаётся opt-in до полевых замеров; не заявляем «быстрее/надёжнее».
- Мы не пишем свой резолвер и не делаем fronting — только выбор транспорта
  и эндпоинтов.
