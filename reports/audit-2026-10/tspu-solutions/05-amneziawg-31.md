# 05 — AmneziaWG 3.1: параметры, честность, UI-редактор

T012 (Critical) + T016 (High). Статус кода: см. коммиты `[tspu-fix]` ниже.
Спека покрывает то, что в код не влезло: UI-редактор, импорт, честные ограничения.

## 1. Что уже в коде (T012)

| # | Изменение | Где |
|---|---|---|
| 1 | Поля 3.1 в плане: `HeaderProtectionKey`, `ContentPaddingAddition`, `RekeyAfterTime/RekeyTimeout/RejectAfterTime/KeepaliveTimeout/MaxHandshakeAttempts`, `RandomTrailers`, `DisableCookies`, `Masquerade*`, плюс `UsesAWG31()` | `core/engine/plan.go` |
| 2 | Валидатор: границы Jc/Jmin/Jmax/S1–S4, `S1+56≠S2`, непересекающиеся H-диапазоны, 32-байтный ключ, `S≥12` при ключе, диапазоны `<uint16>`, CPS-скрипты I1–I5, `matchAWGPublicExample` — запрет публичных примеров (docs.amnezia.org CPS demo, canonical QUIC preset) | `core/engine/validate.go` |
| 3 | Fail-closed: xray отказывается рендерить **любой** AmneziaWG; mihomo отказывается от 3.1-полей; sing-box (with_awg форк) — позитивные тесты, что 3.1 доходит до endpoint verbatim | коммит `58fb4e3` |
| 4 | `wgobfusc.Generate/Generate31` — криптографически случайные наборы, проходящие валидатор, никогда не совпадающие с публичными примерами; пресеты I1 QUIC/DNS/SIP (структура узнаваема, magic bytes случайны) | `core/wgobfusc/generate.go`, коммит `58fb4e3` |
| 5 | Фикстура `enginetest.AmneziaWG3()` | коммит `58fb4e3` |

Ключевое архитектурное решение: **молчаливый no-op запрещён**. Если движок не умеет
применить параметр — план не рендерится (ошибка), а не «рендерится без обфускации».
Выбор движка отсекает 3.1-планы от сборок без `FeatureAmneziaWG3` ещё до рендера.

## 2. UI-редактор AWG (спека, не реализовано — нужен Dart)

Экран редактирования параметров AmneziaWG для сервера. Требования:

### 2.1. Режимы
- **«Сгенерировать» (default):** кнопка вызывает `wgobfusc.Generate` / `Generate31`
  через FFI; пользователь никогда не видит и не копирует параметры вручную.
- **«Вручную»:** текстовые поля Jc/Jmin/Jmax, S1–S4, H1–H4, I1–I5, 3.1-секция.
  Ручной режим помечен бейджем «эксперт»: вставка публичных примеров блокируется
  валидатором с объяснением.

### 2.2. Inline-валидация (все правила — из `validateAmneziaWG`, дублировать буквально)
| Поле | Правило | Сообщение |
|---|---|---|
| Jc | 0–128 | |
| Jmin/Jmax | 0–1280, Jmin ≤ Jmax | «Jmax < MTU» — дополнительно варнинг, если Jmax + 200 > MTU интерфейса |
| S1–S4 | 0–1132/1188/1216/32 | |
| S1 vs S2 | S1+56 ≠ S2 (если оба ненулевые) | «padded init и response столкнутся на N байтах» |
| H1–H4 | число или `a-b`, диапазоны не пересекаются; `1/2/3/4` = «механизм выкл» | подсвечивать пересечения пар |
| HeaderProtectionKey | base64/hex ровно 32 байта | при установке требовать S1–S4 ≥ 12 (авто-поднять с подтверждением) |
| 3.1 ranges | `a-b` или `a`, uint16 | |
| I1–I5 | CPS-теги `<b>/<c>/<t>/<r>/<rc>/<rd>` | |
| Публичные примеры | точное совпадение с `matchAWGPublicExample` | «этот набор опубликован и сигнатурится цензором — сгенерируйте свой» + кнопка генерации |

### 2.3. Пресеты мимикрии
Селектор «I1 как»: QUIC / DNS / SIP / случайный. Подстановка через
`wgobfusc` preset-функции (magic bytes всегда случайны — пресет не превращается
в сигнатуру). Показывать hex-превью первых 32 байт I1.

### 2.4. Применение
- «Применить» недоступна, пока есть ошибки валидации (не варнинги).
- После применения: показать fingerprint-саммари (длины, диапазоны) — не сами
  секреты; ключ маскируется.
- Кнопка «проверить на сервере»: dry-run handshake с замером (см. §4).

## 3. Импорт `vpn://` URI + QR (спека)

Формат: `vpn://awg/<base64url(json)>`, где JSON = поля `engine.AmneziaWG` + минимум
для подключения (адрес, ключи). Парсер — в `core/parser` (Go), QR — существующий
`app/lib/src/ui/qr.dart` + `addserver.dart` (Dart).
- Импорт валидирует через тот же `validateAmneziaWG`; публичные примеры
  отклоняются с предложением регенерации.
- Экспорт сервера в QR: только по явному действию, с предупреждением
  «ключи в QR видит любой, кто его отсканирует».

## 4. Замерный стенд (спека, не код)

T012 требует «собственный замерный стенд». Минимум:
- Клиент sora + эталонный сервер AmneziaWG (kernel module / userspace).
- Сценарии: handshake с 2.0, с 3.1, с битой обфускацией (ожидаем fail, не silent WG).
- DPI-эмуляция: entropy-тест заголовков, size-distribution (16-байтные паттерны),
  timing-анализ rekey/keepalive при фиксированных vs range-таймингах.
- Метрика: доля сессий, классифицированных эмулятором как WireGuard.
- Статус ateo.digital/vpnsmith противоречив — стенд должен быть свой,
  воспроизводимый в CI (docker-compose).

## 5. T016: честный статус

| Подпункт | Статус |
|---|---|
| Побайтовый валидатор QUIC-мимикрии | **Нет.** Пресеты формируют структуру, но сверки с реальными QUIC-фингерпринтами (quic-go/Chrome) нет. Нужен тест на захвате. |
| Probe-resistant UDP-ответы | **Нет, и это серверная сторона.** Клиент не может заставить чужой сервер молчать на пробы. Только для своих серверов (документировать). |
| Модель таймингов | **Частично.** 3.1 range-тайминги рандомизируют rekey/keepalive; поведенческой модели (распределение межпакетных интервалов под протокол-донор) нет. |
| Mimicry-padding вместо random | **Частично.** `ContentPaddingAddition` есть; padding под распределение длин донора (а не uniform random) не реализован. |
| Двусторонняя мимикрия | **Нет.** AWG CPS односторонняя из коробки: ответы сервера остаются WG-shaped. Требует серверной кооперации — вне зоны клиента. |

## 6. Честные ограничения (говорить пользователю)

1. **Китай — не AWG.** Против GFW рекомендовать VLESS/XHTTP; AWG — для
   DPI среднего уровня (реестры, ТСПУ-фильтры без AI-классификатора).
2. **3.1 требует обе стороны.** Сервер без 3.1 + клиент с 3.1 = не соединится;
   UI обязан это объяснять, а не молча падать.
3. **sing-box upstream не умеет AWG** — только with_awg форк (amnezia-box);
   выбор движка это учитывает, рендер — нет (fail-closed вместо no-op).
4. **Генерация ≠ невидимость.** Уникальные параметры защищают от сигнатур,
   но не от поведенческого анализа — см. T016 выше.
5. Публичные примеры из гайдов/блогов **запрещены валидатором** — это фича,
   а не баг: их копипаст делает всех пользователей одной сигнатурой.
