# WAVE-SEAMS — отдел совместимости стыков: итоговый отчёт

Ветка `bugfix/audit-2026-10-19` (sora + sora-legacy). Метод: инвентаризация
каждого стыка → исполняемая проверка (контрактный тест, спаренные пробы
реальными данными, round-trip) → фикс → пин тестом → независимое ревью
(исполнитель + ревьюер на каждый фикс; ревьюеры работали мутациями и
собственными корпусами, а не по текстам авторов).

**Итог: 21 коммит (sora 16, legacy 5), все прошли независимое ревью.**
Открытых разрывов с фиксами «в стол» не осталось: что не чинилось на месте,
оформлено спеками с приёмкой (§6). Фрагменты кластеров и все ревью:
`reports/seams/s1…s5-*.md`, `*-review.md`.

## 1. Критичные находки (живые пути были сломаны)

1. **F9-пэйринг был мёртв** (S4, `ba625cf3`). Dart
   `SyncPairing.decodePairPayload` отвергал **все** валидные QR: стоковый
   `base64Url.decode` бросает на непаддированных 43/22-символьных пэйлоадах;
   собственный `sync_qr_test.dart` падал на 4 accept-кейсах. Плюс длина id в
   UTF-16 вместо UTF-8 байт, пробелы в port, неканонические trailing-биты.
   Ревью: спаренный Go↔Dart корпус 155 кейсов (настоящие Go-пэйлоады,
   переборы trailing-битов) — вердикты идентичны 155/155.
2. **Revocation расширений в проде не существовал** (S4; `58a22c32`,
   `ce1ab25b`, `b4f4cf28`, REJECT-фикс `b015cef1`). Установка из Dart UI не
   проходит через ядро (в proto нет Install/SetEnabled RPC, Dart-клиента
   ext-сервиса нет), Go Store в проде никто не вызывает, реестры Go и Dart
   физически не пересекаются, `RevocationCache.Refresh` не вызывался нигде:
   отозванное валидно-подписанное расширение ставилось и работало у всех
   пользователей бесконечно. Построена Dart-сторона целиком по Go-семантике:
   парсер (лимиты/констрейнты/строгие поля), проверка подписи существующими
   примитивами, кэш в Dart-реестре, enforcement на install/setEnabled/старте
   панели, свип при load, триггеры refresh, локализованные отказы. 36 тестов.
   Ревьюер обойти гейты не смог; его серьёзное замечание (свип стирал
   указатель отката `previous` через `copyWith` — откат отозванного был
   сломан в главном сценарии) закрыто REJECT-фиксом и пере-ревьюнуто.
   Остаток по дизайну: командный ключ — placeholder, fetch fail-closed до
   key ceremony (как и в Go) — механизм вооружён и протестирован.
3. **Dart-каталог расширений не компилировался** (S4, `d508247f`) —
   `sha256` затенялось собственным полем; плюс валидация слабее Go по 6
   пунктам. И **манифест-парсер Dart** был слабее Go (S4, `7aa0819f`):
   public_key — только non-empty вместо minisign-envelope, nested unknown
   fields проглатывались, лимиты в UTF-16, `manifest_version: 1.0`
   принимался. Остаточные 3 расхождения ревью (offset RFC3339, raw-длины
   author, wildcard-лимит) закрыты `d13971f5` спаренными корпусами 72/72;
   заодно исполнитель доказал, что Go принимает offset ≤24:60 — строгий
   RFC создал бы обратный разрыв, запинена Go-точная граница.
4. **Редакторы логов обоих репо не маскировали составные токены** (S5,
   sora `5f9013c7`, legacy `d92ec9a`): `access_token`, `refresh_token`,
   `session_token`, `accessToken`, `Authorization: Bearer/Basic` уходили в
   логи дословно (`\btoken\b` внутри составного ключа не срабатывает).
   Зеркальный фикс + пин; ревьюер подтвердил отсутствие ложных срабатываний
   (`tokenizer`, `token_count` не маскируются — верно).
5. **legacy принимал все битые REALITY/XHTTP** (S5, `417dc76`): любой
   pbk/sid, любой XHTTP-mode, vision-на-XHTTP, unknown protocol/transport.
   Портированы валидаторы sora + белые списки; паритет запинен
   `TestValidateRealityParity` (ревьюер прогнал 23 своих вектора — вердикты
   и тексты ошибок совпали по всем).
6. **legacy терял пароли и целые форматы** (S5, `6379922`): trojan/hy2
   пароль парковался в UUID (порт фикса интеграции); SIP008 импортировал
   0 серверов. В sora SIP008 параллельно починил отдел серверов
   (`215645e5`, проверено на HEAD).
7. **legacy `verifyTpws` никогда не срабатывал** (S3, `375cb10a`): zapret
   build не дописывал дайджесты tpws/nfqws в SHA256SUMS — поставленный tpws
   исполнялся без проверки. Ревью: эмуляция + исполняемый тест через
   настоящий verifyTpws — строгая ветка достижима, подмена отвергается.

## 2. Разрывы средней тяжести (исправлены)

- **pbjson-дрейф 1.11** (S1, `ff3a7f95`): `OutboundSpec.flow/flow_auto`
  были в proto, Go и pb.dart (UI показывает бейдж), но отсутствовали в
  Dart pbjson-дескрипторе — JSON-кодек терял бы flow. Пин
  `dart_descriptor_parity_test.go` сверяет все 133 дескриптора поле-в-поле;
  по итогам ревью усилен (`5f98a724`): запинены $json-карты, стриминг-форма
  стабов и строгое nested-сравнение (мутации ревьюера M2/M3/M4 ловятся).
- **install.sh отвергал binary-mode SHA256SUMS** (S3, `3860be97`) —
  единственный из 4 читателей формата; round-trip в обеих формах запинен
  фактическим прогоном через grep + `sha256sum -c`.
- **nfpm-app не объявлял pkexec/minisign** (S3, `924f2201`) — обновление на
  чистой системе предлагалось и умирало внутри хелпера.
- **postremove не снимал nft-таблицы ядра** (S3, `b14a97d7` + строка
  `sora_ingress`, доехавшая параллельной работой, проверено на HEAD): при
  убитом ядре и удалении пакета таблицы kill switch / nfqws / ingress
  оставались без владельца.
- **XPaddingBytes без гейта** (S2, `acfcab37`): padding-only XHTTP-план
  селектился на любой движок, Xray/sing-box молча роняли значение. Теперь
  требует `FeatureXHTTPXmux` (прецедент класса PASS3 S1).
- **Микс tpws/nfqws терялся молча** (S2, `934ce3e7`): 18 legacy-полей
  проходили валидацию и уходили в nfqws без шейпинга. `validateDesync`
  честно отвергает микс; продюсеров микса в репо нет (проверено ревьюером
  матрицей 20 кейсов + геномной сеткой 144 комбинации).

## 3. Стыки, вердикт СОВМЕСТИМ (с доказательствами)

- **proto ↔ Go ↔ Dart**: 40/40 RPC на трёх сторонах, стриминг 5/5, 125
  сообщений и 8 enum по номерам/именам/типам; `GetBenchmarks` — осознанно
  RETIRED (PASS1 M3), стабы есть. Негоциация версий: Dart 1.11/min 6, core
  1.11/min 1, семантика одна, `TestVersionContract`/`TestNegotiate` зелёны.
- **ARB**: 32 файла × 666 ключей, missing/extra = 0, ICU-плейсхолдеры и
  геттеры совпадают. errs.Key → UI: сырой ключ пользователю не показывается
  никогда (только локализованные fallback) — но специфичность: 21 ключ
  падает в безликую errGeneric, спека в s1-фрагменте §3.
- **Capabilities ↔ рендереры**: матрица 21 фичи — каждый клейм HEAD
  подтверждён рендерером + гейтом; F8-пин жив; условные клеймы sing-box
  сверены с тегами реального lx.22. Бинарные проверки на новых пинах:
  sing-box `check` и mihomo `-t` — PASS (вкл. amneziawg3, vless-encryption,
  split-XHTTP).
- **zapret argv ↔ вендорный CLI**: все токены tpws/nfqws сверены с
  getopt/help исходников; fake-пейлоады: фикс «assetsDir смотрит не туда»
  жив и запинен тестом; путь `<assets>/fake/<имя>` доезжает через build.sh.
- **Sync**: kinds (6), allowlist (38 ключей, источник — Dart, Go — opaque
  blob), токен (Bearer, const-time, файл 0600), mDNS `_sora-sync._tcp`,
  LWW-конфликты — совместимы по коду/контракту/тестам; все пакеты
  service/sync зелёны.
- **Расширения, 5 поверхностей**: permissions (12), Risk, capabilities (6),
  bridge-методы TS↔Dart↔Go совпадают (существующие пины); 4 shipped
  .soraext проходят все поверхности фактически (схема, Go, CLI, Dart
  open+verify).
- **Пакеты ↔ runtime**: движки+digests, geo, zapret fake, сокет/пайп,
  polkit-id, пути sora-update, desktop/icon — сходятся по обе стороны;
  имена релизных артефактов (12 форм) доказаны манифестом реального
  релиза 1.0.5 + тестами; SHA256SUMS прогнан через все 4 парсера.
- **Внешний импорт**: списки/base64, все схемы ссылок, WG .conf, Xray
  JSON/Remnawave, sing-box JSON, Clash YAML — реальными образцами;
  отдельного формата экспорта Happ не существует (обещание честное);
  все 7 форм диплинков соответствуют `links.dart`.
- **Docs ↔ код**: 14 env, 13 CLI-флагов, ~45 путей, RPC из docs — всё
  существует; битых markdown-ссылок 0 в обоих репо.

## 4. НЕ ПРОВЕРЯЕМО ЗДЕСЬ (точные причины)

- Xray + WireGuard на пине 26.10.17: `run -test` падает на создании kernel
  WG — в VM нет `/sys/module/wireguard`; окружение, не схема (отделу
  бампов: хост с kernel WG или решение по `noKernelTun`).
- Живой nfqws packet-run: нет `nfnetlink_queue` в ядре VM.
- Полный `test_update.py`: нет bwrap (гоняет CI). Inno/pwsh, настоящий
  minisign round-trip — ключ placeholder по дизайну, fail-closed согласован.
- mDNS по живому эфиру: нет multicast в песочнице (код+контракт+тесты —
  проверены).

## 5. Инциденты с общим индексом

За время отдела зафиксировано и нейтрализовано **не менее 6 эпизодов**
staged-ревёртов чужих и своих свежих коммитов (механизм разъяснён
форензикой волны A: `git checkout <old rev> -- <paths>` и stale-снапшоты —
в AGENTS.md уже внесён запрет). Лично лидом сняты 3 эпизода (11 + 10 + 7
файлов, включая попытку ослабить interop REALITY-пин и откатить бамп
движков), остальные агенты снимали точечно по своим путям. **Потерь в HEAD
и истории — ноль**; на момент сдачи оба индекса чисты. Предупреждение
соседям: worktree-копии файлов из эпизодов могут содержать до-бамповое
содержимое — отделам движков/интеграции стоит сверить свои горячие файлы с
HEAD перед следующими коммитами.

## 6. Открытые спеки (не чинилось — чужие горячие зоны / решения владельца)

Из фрагментов, с приёмкой в каждом пункте:
- **S5-SP2 (важно, одна строка)**: sora отвергает UUID v6–v8
  (`uuidRE [1-5]` против `[1-8]` в legacy) — v7-UUID от Remnawave и др.
  отбраковываются. parser.go — горячая зона отдела серверов; приземлить
  первым делом, когда остынет, вместе с портом
  `TestParserAcceptsNewerUUIDVersions`.
- **S5-SP6**: sing-box/Clash импорт: REALITY/TLS/WS доезжают только сырым
  JSON в Options; plan-конверсия (`core/control/plan.go` обоих репо) не
  извлекает pbk/sid/path в типизированные поля — REALITY из таких подписок
  падает на ValidateReality (sora) / молча без REALITY (legacy).
- **S5-SP3/SP4/SP5**: структурные порты в legacy — SIP002 ss_plugin
  end-to-end; XHTTP-поля в Transport (downloadSettings/xmux/padding);
  ECH/KeyShare валидация.
- **S2-C2**: поля одного рендерера без гейта в MissingFor — прежде всего
  `TLS.KeyShare` (только mihomo; против REALITY-серверов Xray ≥26.9.8
  с hybrid — непрозрачный обрыв хендшейка); файл catalog.go отдела бампов,
  спека по прецеденту AWG J1/J2/J3 готова.
- **S2-Z2**: proto BypassStrategy несёт 7 полей из 29 Go — nfqws-стратегии
  и часть tpws-полей по проводу недоступны (внутри core потерь нет);
  фикс — proto + buf generate + Dart regen, владельцы proto/тулчейнов.
- **S3 РАЗРЫВ-1**: sora-sync не поставляется ни одним пакетом (F9 из
  установленных сборок недостижим) — решение владельца по размеру пакета;
  интерфейс полностью согласован, спека поставки из 4 пунктов в фрагменте.
- **S3 РАЗРЫВ-2/5**: winws.exe для Windows-NFQWS не поставляется и не
  пройдёт digest-гейт (fail-closed задокументирован); legacy поставляет
  nfqws, который его ядро не ищет (мёртвый груз) — продуктовые решения.
- **S1 §3**: 21 core.* error-ключа без специфичной локализации (падают в
  errGeneric) — спека: ARB-ключи одним коммитом после отдела тулчейнов.
- **S4 minor**: default data-dir демона ≠ приложения — страдает только
  ручной reuse демона; канонический путь — решение владельца.
- **Соседний предсуществующий дефект** (нашёл ревьюер S2, не фиксы отдела):
  геномы tune `Method=split|disorder + FakeProto` конвертируются в
  стратегии, которые валидация отвергает (32 комбинации, fail-closed) —
  отдельная задача отделу tune/nfqws.
- **З-3**: Dart-парсер списка отзыва строже Go по trailing-данным/UTF-8 —
  расхождение в безопасную сторону; рекомендация — затягивать Go, а не
  ослаблять Dart (владельцам core/ext).
