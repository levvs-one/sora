## 1. Что сделано — по раундам

**Раунд 1 (4 параллельных агента):**
- sora Go-ядро: 42 пункта (все 7 P0-High кодовой части, 16 Medium, 19 Low), каждый отдельным коммитом, `go build` + `go vet` после каждого.
- sora Dart/UI: 13/13, включая H8 (потеря `sora://`-ссылок на Linux) и UI-мелочи.
- sora-legacy Go: пробер больше не сканирует приватные сети, redactor, `MaxItems`-эквиваленты, docs-требования для Android, исправлены формулировки прошлых аудитов.
- sora-legacy C#: 10 коммитов — SHA-256 верификация скачанных движков, запрет downgrade, закрыт произвольный запуск файлов, Mutex, спидтест на HTTPS.

**Раунд 2 (верификация + повторный поиск):**
- Spot-check 18 исправлений раунда 1 — ошибок не найдено.
- Найдено и исправлено 4 новых бага: NEW-1 (sora: `ip`/`nft` резолвились через PATH в root-демоне), NEW-R2-1 (незакрытый HttpClient в C#), NEW-R2-2 (`http.DefaultClient` уводил метрики в пользовательский прокси), NEW-R2-3 (SHA-256 для geoip/geosite.dat).
- Добор пропусков: SORA-L8 (provenance third_party-бlобов), SORA-L18 (документация DNS), LEGACY-M8 (pin всех GitHub Actions по SHA, dependabot).

**Раунд 3 (качество + регрессии):**
- Найдена и исправлена регрессия e2e-теста: взаимодействие фиксов M1 (обёртка `countedConn`) × H2 (проверка пира в handshake). Починено без ослабления безопасности + новый регрессионный тест. `TestClientTalksToTheCoreOverTheTransport` зелёный 3/3.
- Контроль качества всех 75 коммитов: найден 1 мнимый фикс (NEW-1 использовал `exec.LookPath`, который сам идёт через PATH) — переделан по-настоящему: резолв из фиксированных системных каталогов, fail-closed.
- UI/UX-проход по требованию владельца: приложение уже на уровне — сырых ошибок в UI нет (всё через `CoreFailure` → локализация), красного хардкода нет, все строки через `S.of(context)` (31 язык), состояния loading/error/empty везде, overflow обработан. Исправлений не потребовалось.
- Слоп-маркеров (TODO/FIXME/HACK) в новом коде: ноль.
