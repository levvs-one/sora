## Находки

### F1. Sheet подписки игнорировал скопированные `sora://`-ссылки — ПОФИКШЕНО
- Файл: `app/lib/src/ui/subscription_sheet.dart:24`
- Сценарий: пользователь копирует `sora://add/https://…` из мессенджера → открывает «Добавить подписку» → поле пустое (префилл работал только для голого `https://`). При этом QR-сканер такие ссылки уже умел и вёл в этот же sheet — поведение было несогласованным.
- Фикс (коммит `008891b`): префилл через `parseImportLink` — извлекается URL и имя; sealed `happ://crypt…` по-прежнему не префиллится (sheet их не умеет).
- Вердикт фильтра: **PASS** — закрыт реальный разрыв флоу, ноль нового UI, поведение согласовано с QR-флоу.

### F2. Синк врал «Paired» при повторном сканировании — ПОФИКШЕНО
- Файл: `app/lib/src/ui/sync.dart:56`
- Сценарий: сканировать один и тот же pairing-QR дважды → `SyncDevices.add` молча игнорирует дубликат, а снекбар всё равно говорил «Paired».
- Фикс (коммит `8beec69`): снекбар только если устройство реально добавлено.
- Вердикт фильтра: **PASS** — честность, 3 строки, без нового UI.

### F3. Rollback/uninstall расширения могли молча не сработать — ПОФИКШЕНО
- Файл: `app/lib/src/ui/extensions/detail_screen.dart:322`
- Сценарий: confirm → `store.rollback`/`uninstall` бросает (диск/registry) → catch глотал всё, диалог уже закрыт, пользователь в недоумении жмёт ещё раз.
- Фикс (коммит `c8ff815`): снекбар с существующей локализованной `extErrGeneric`.
- Вердикт фильтра: **PASS** — тихий провал кнопки = нечестный UI; фикс использует штатный паттерн приложения, без новых строк.

### F4. Ошибка сохранения настроек расширения + форма врала — ПОФИКШЕНО
- Файл: `app/lib/src/ui/extensions/detail_screen.dart:345`
- Сценарий: `store.setSettings` падает (persistence) → catch молчал, а форма продолжала показывать несохранённые значения как сохранённые. Комментарий «validation errors are shown inline by the form» при этом был неправдой — инлайн-ошибок в форме нет вообще.
- Фикс (коммит `c8ff815`): снекбар `extErrGeneric` + перечитывание значений из стора (`_loadSettings`), чтобы форма показывала правду.
- Вердикт фильтра: **PASS** — убран фейковый комментарий и фейковое состояние; без перечитывания фикс был бы полумерой (слоп).

### F5. Ошибка подключения цепочки подавлялась навсегда — ПОФИКШЕНО
- Файл: `app/lib/src/ui/chains.dart:30`
- Сценарий: тап по битой цепочке → тост `chainHopMissing`. Тап по *другой* цепочке с тем же ключом ошибки → тишина: `reportFailure(source: 'chain-connect')` дедуплицирует по source+key, а `recovered('chain-connect')` нигде не вызывался (в отличие от connections/programs/logs, где recovered на успехе есть).
- Фикс (коммит `07aaa41`): `recovered` после успешного `connectChain`.
- Вердикт фильтра: **PASS** — однострочник, делает дедуп честным: повторы давятся, но не вечно.

### F6. [cross-ref] Удаление выбранной подписки оставляет висячий `settings.server`
- Файлы: `app/lib/src/sora.dart:1293` (`deleteSubscription`), `:602` (`_watchSubscriptions`), `:410` (`nameOf`), `:1803` (`buildPlan`).
- Сценарий: удалить подписку, через сервер которой идёт выбор (или единственную) → `settings.server` указывает на мёртвый id. Home-карточка показывает сырой id (`nameOf` fallback'ится на id), а `connect()` строит план с `proxyTarget = <мёртвый id>` при живых outbound'ах — ядро получает план с несуществующим таргетом. Пользователь чинит только ручным перевыбором сервера.
- Не чиню: правильный фикс — сброс `settings.server` в `'auto'` при исчезновении выбранного сервера — должен жить в `sora.dart` и покрывать внешний delete через `_watchSubscriptions`. UI-полуфикс был бы слопом.
- Вердикт фильтра: **PASS как находка** — реальное битое состояние, не косметика.

### F7. [cross-ref] Битый deep link — тихий no-op
- Файл: `app/lib/src/desktop/desktop.dart:510` (`_open`).
- Сценарий: клик по `sora://` с невалидным содержимым → `parseImportLink` вернул null → `return`, ноль обратной связи. Пользователь думает «не сработало».
- Не чиню: вне моей зоны; естественный фикс — `reportFailure`/нотификация через существующий pipeline.
- Вердикт фильтра: **СПОРНО** — с одной стороны честность требует сказать, с другой — мусорные ссылки из чужих приложений не должны спамить. Помечаю как суждение владельца, не протаскиваю.

### F8. Профили: автоматч никогда не срабатывает (flow gap, не баг)

- Вердикт фильтра: **не чинить в UI** — код честно задекларирован как заглушка, фейковой «работы» нет. Отмечаю как известное ограничение.

### F9. Синк «показать код» ждёт вечно (flow gap, не баг)

### F10. Очистка логов/уведомлений и удаление правила — без confirm (суждение, оставляю)
