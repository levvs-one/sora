# A11y-прогон — агент №8 (Доступность)

Зона: `sora/app/lib/src/ui/` + `sora/app/lib/src/design/` (theme.dart). Flutter SDK в среде нет — только статическое чтение кода, без запуска и без widget-тестов. Отчёты FEATURE-REPORT.md / REVIEW-5PASS.md по accessibility ничего не содержали — дублирования нет.

Ко всем рекомендациям ниже применён **фильтр слопа** (директива владельца): отсекаются «модные, но пустые» решения, визуальный и функциональный шум, фейковые фичи. У каждой рекомендации указан вердикт фильтра. Спорные пункты помечены честно, а не протащены.

## Что исправлено (коммиты `[power-run]`, без пуша)

Основная часть правок ушла в историю через общие коммиты power-run (дерево shared, см. «Инцидент» ниже); финальный коммит `86b8742` → после перестановок коллег итоговый HEAD `5bcc46f` содержит всё нижеперечисленное, дерево консистентно (проверено: все маркеры на месте, баланс скобок, `Tile(selected:)` закрывает `selected:` из chains.dart, `Pressable(semanticButton:)` закрывает 5 мест использования).

1. **`Pressable` получил opt-in `semanticButton`** (kit.dart): обёртка `Semantics(button: true, enabled:)`. До этого текстовые кнопки без своей Semantics (reconnect-баннер, crash-бanners, карточка сервера на home, cancel в about/field-sheet, action в строке нотификации, close в subscription) скринридером как кнопки не анонсировались — читался только текст. Вердикт фильтра: **проходит** — невидимо для зрячих, реальный гэп для SR; opt-in, а не поведение по умолчанию, чтобы не плодить вложенные button-ноды там, где Semantics уже есть (RoundButton, Segments, speedtest/servers).
2. **`Tile`: `Semantics(button: true, selected:)` при `onTap != null` + новый параметр `selected`** (kit.dart, chains.dart): строки-пикеры серверов в ChainBuilder теперь анонсируют выбранность (раньше чекбокс был чисто визуальным). Вердикт: **проходит** — та же схема, что уже используется в `Segments`/`servers.dart`.
3. **`Semantics(checked:)` на кастомном чекбоксе** подтверждения опасных разрешений (extensions/permissions_sheet.dart:165) — иконка `check_box_*` сама по себе семантики не несёт. Вердикт: **проходит** — без этого SR-пользователь не узнает состояние; альтернатива (настоящий Checkbox) была бы визуальным шумом.
4. **Actionable-тосты**: `_ToastTitle` с `Semantics(button: true, onTap:)` когда у нотификации есть action (toasts.dart). Пустые тосты остались текстом. Вердикт: **проходит** — честно отражает «весь тост тапабелен»; частичность (только title-зона) отмечена, третьего API у toastification нет.
5. **`Semantics(button: true)` на `_QuietButton`** (extensions/detail_screen.dart:330).
6. **`Tooltip(message: s.remove)` на иконке сброса rename** (subscription.dart:278) — была единственной иконкой-кнопкой без подписи и без тултипа (соседняя hide/unhide обёрнута в Tooltip). Вердикт: **проходит** — консистентность с соседним паттерном, новой строки локализации не потребовалось.
7. **`ExcludeSemantics` на декоративном**: `UsageBar` (рядом всегда текст «X из Y»), оба `LinearProgressIndicator` в benchmark (прогресс уже озвучен строкой «done of total»), `QrImageView` в qr.dart и sync.dart (для SR QR — шум; пейлоад доступен через кнопку копирования; в pairing-скрине токен намеренно не дублируется текстом — требование безопасности, см. комментарий в коде). Вердикт: **проходит** — убирает шум, ничего не скрывает из того, что SR-пользователь мог бы использовать.
8. **Масштабирование текста**: `Segments` (36), кнопки `confirm()` (52/44), cancel в field-sheet (44), `_QuietButton` (52) — фиксированная высота → `minHeight`; значение `ChoiceTile` — `Flexible` + `maxLines: 1, ellipsis` (при крупном шрифте был бы RenderFlex-overflow). Вердикт: **проходит** — при дефолтном масштабе ноль визуальных изменений.

## Находки (не исправлено — с вердиктом фильтра)

### Semantics / скринридер
- **F1. Reorder цепочек недоступен с клавиатуры/SR** (chains.dart:326): `ReorderableListView` + drag-handle; переупорядочить можно только драг-жестом. Правильное решение — `customSemanticsActions` («Move up/down») на строках: невидимо, реально работает. **Не сделано**: нет строк `chainMoveUp/chainMoveDown` в ARB, а добавлять локализацию без тулчейна и регена — риск; лепить подписи из чужих строк — нечестно. Вердикт: **отложено честно**, рекомендация — добавить 2 строки и `CustomSemanticsAction` (код тривиален). Видимые up/down-кнопки **отвергнуты фильтром** — визуальный шум ради редкого действия.
- **F2. Кнопка контекстного меню подписки анонсируется именем подписки** (servers.dart:647: `label: state.displayName`): роль «menu» не отражена. Идеал — «More options for X», но строки нет. Вердикт: **не трогать сейчас** — текущая подпись хотя бы идентифицирует, чьё меню; inventing строк — слоп.
- **F3. Тосты гаснут через 5 секунд** (toasts.dart:98): `pauseOnHover` спасает только десктоп; на мобиле SR-пользователь может не успеть. Смягчение: нотификации живут в NotificationsScreen. Вердикт: **наблюдение, не баг** — менять тайминг глобально было бы «модным» фиксом без данных.
- Ок: Orb (home.dart:112: `button/toggled/label`), сайдбар (Semantics selected + Tooltip с хоткеем), speedtest/servers-селекторы (`selected+button`), StarRating (скрытая Semantics-подпись), DNS-строки (иконка warning/check + текст, не только цвет), collapse/expand кнопки (`expanded:`), SwitchTile (CupertinoSwitch несёт `toggled` сам).

### Touch targets (<48dp)
- **F6. `RoundButton` 36×36** (kit.dart:130) — везде: app-бары, строки цепочек/подписок, тулбар QR. Вердикт: **не увеличивал** — 48dp сломает текущую компоновку и эстетику; решение за дизайн-владельцем. Зафиксировано как известный компромисс.
- Toast-close 30×30 (toasts.dart:125), пункты сайдбара 40px высотой, speedtest-строки minHeight 28 — аналогично, только фиксация.

### Фокус / клавиатура (desktop)
- Ок: `Pressable` — `FocusableActionDetector` + Enter/Space (`ActivateIntent`), видимый фокус-бордер; `InkWell`/`MenuItemButton`/`TextButton`/`TextField` — нативные; Tab-порядок естественный.
- Ок: **Esc закрывает все диалоги** — `confirm()`, `showFieldSheet` (`barrierDismissible: true`), `showDialog` в permissions/detail (дефолт `true`); подтверждено по документации Flutter (barrierDismissible ⇒ Esc pops route).
- Меню (`MenuAnchor`): нативная клавиатурная навигация.

### Reduce motion
- Ок: `MotionScope.of` читает `MediaQuery.maybeDisableAnimationsOf`; `Motion.of/enabled` используется в `push()`, `confirm()`, `showFieldSheet`, тостах, `Glow` (тикер останавливается), tour (`disableScaleAnimation`, `TourScrim` duration). Система «отключить анимации» уважается везде. `MotionScope` нигде не инстанцирован — апп-тумблер отсутствует, но это не нарушение: системной настройки достаточно, лишний тумблер был бы шумом (вердикт фильтра).

### Масштабирование текста — дополнительно
- `Tile.title` — `maxLines: 2 + ellipsis`, ок. Заголовки `Screen`, пустые состояния (`textAlign: center`) — ок. Диалоги `confirm`/`_FieldSheet` — `mainAxisSize.min`, длинные вопросы переносятся, ок.
