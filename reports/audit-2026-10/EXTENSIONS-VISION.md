# Расширения sora — видение (дополнение к FEATURE-PLAN.md, секция F10)

**Позиционирование:** sora — лучший VPN-клиент вообще, включая коммерческие. Расширения — ключевой дифференциатор.

## Принципы (без компромиссов)

1. **Расширения умеют буквально всё.** Примеры из требований владельца:
   - живёшь в РФ — ставишь расширение с обходом нового DPI/блокировки («ебнуть обход для антигравити» — пожалуйста);
   - хочешь красную тему на Windows — пожалуйста;
   - и так — любое: протоколы, транспорты, правила маршрутизации, UI-моды, виджеты, автоматизация.
2. **Быстро и удобно** — установка в один тап, обновление фоном с откатом, отключение одним тапом. По лучшим канонам IT 21 века: декларативный манифест, hot-reload настроек, понятные ошибки.
3. **Доверие и репутация:**
   - каждый создатель подписывается (подпись расширения ключом автора + подпись каталога);
   - у каждого создателя — свои звёзды/рейтинг прямо в приложении (оценки, число установок, бейджи: «проверен командой sora», «топ недели»);
   - отзывы и жалобы видны; вредоносное — снимается с каталога с отзывом подписи (revocation).
4. **Свой стиль, не копия Chrome Web Store:** функциональнее и удобнее — живые превью, фильтры по возможностям («темы», «обходы», «протоколы»), подборки, настройки каждого расширения прямо в карточке.
5. **Безопасность без уступок:** permissions-модель как у мобильных ОС (расширение просит только нужное, пользователь видит список до установки); песочница; расширения не могут тихо читать секреты подписок — доступ к credentials только через явный permission с предупреждением.
6. **Открытость:** каталог прозрачен (исходники linked, reproducible builds где возможно); sideload — только с явным предупреждением о рисках.

## Что это меняет в F10 (волна 3)

- API расширений должен покрывать: темы/UI, сетевые хуки (DPI-обходы, транспорты), правила маршрутизации, фоновые задачи, виджеты.
- UI стора: карточки с рейтингом создателя, звёзды, бейджи, поиск, категории, настройки внутри карточки, один тап на всё.
- Модель данных создателя: identity, публичный ключ, рейтинг, статистика — часть манифеста каталога.
- MVP волны 3 обязан включать: установку/удаление/обновление/откат, permissions-экран, звёзды и подпись создателя. Без этого не «великолепно».

**Стандарт:** никаких ошибок, уступок и компромиссов — каждая деталь продумана.

## Инженерный принцип: адаптируемость и управляемость

Весь код — адаптируемый, управляемый, удобный: выпустить обнову должно быть легко.
- Модульность: фичи изолированы, зависимости явные, конфиги декларативные.
- Обновления: staged updates (F7) с прогрессом и откатом; миграции данных версионированы и обратимы.
- Наблюдаемость: логи, метрики и диагностика позволяют понять поведение без чтения всего кода.
- Работа безупречно: каждый релизный путь (установка → обновление → откат) покрыт тестами и ручными чек-листами.
