# Конкурентный анализ Sora и roadmap «лучшего клиента»

Дата: 2026-10-19. Источники: README/PLANS/CHANGELOG/docs репозитория `sora`, веб-исследование GitHub-репозиториев, официальных сайтов и обзоров конкурентов. Неподтверждённые данные помечены `?`.

Легенда таблицы: ✓ — есть, ✗ — нет, ~ — частично, ? — не подтверждено источниками.

## 0. Что умеет Sora сегодня (база для сравнения)

**Ядро и протоколы:** 3 движка (sing-box, Xray, mihomo) с автовыбором под сервер по capabilities; VLESS/VMess/Trojan/Shadowsocks/Hysteria2/TUIC/WireGuard/AmneziaWG/SOCKS/HTTP(S); REALITY, XHTTP, VLESS Encryption, фрагментация TLS.
**Подписки:** HTTPS-ссылки, Xray JSON (Remnawave), обновление по расписанию, трафик/срок, объявления провайдера, свой User-Agent; deep-links `sora://`, `happ://`, `v2rayn://`, `clash://`, `hiddify://`, `sing-box://`.
**Режимы:** TUN (адаптер `sora0`) и системный прокси; kill switch (nftables/WFP, встаёт до запуска ядра); бессерверный DPI-обход через zapret (Linux).
**Маршрутизация:** правила для сайтов/IP/программ (напрямую/через VPN/блок), пресеты (всё через VPN, Россия напрямую, Иран, Китай), блокировка рекламы, свой DNS, IPv6-переключатель.
**Надёжность:** выбор быстрейшего по задержке, fallback-группы по ролям в названиях (mihomo), переподключение при смене сети/сне, супервизор перезапуска ядра, сосуществование с другими VPN.
**Сервис:** автообновление с проверкой SHA256 (приложение+служба), трей, автозапуск, подключение при старте.
**UX:** тосты + история 100 уведомлений, журнал с категориями/поиском/экспортом (8 форматов), диагностика (HAR из встроенного браузера, PCAPNG-захват TUN, EVTX), встроенный браузер со списком speedtest-сервисов, 31 язык, светлая/тёмная темы, онбординг, хоткеи.
**Безопасность:** приложение (Flutter, от пользователя) → gRPC → служба `sora-core` (Go, LocalSystem/`sora`); конфиг ядрам через stdin; хранилище подписок AES-256-GCM (DPAPI/файл); маскирование секретов в журнале; загрузка подписок только HTTPS, защита от SSRF (запрет редиректа интернет→LAN).
**Платформы:** Windows 10 1809+/11 x64, Linux x64 (deb/rpm/Arch). Android заявлен в описании репозитория, но в `app/` есть раннеры только `windows` и `linux` — фактически не выпущен. iOS/macOS нет.
**Уже запланировано (PLANS.md):** расширения (P1), UX split-tunneling (P0), диагностика автовосстановления (P0), улучшение автовыбора ядра (P0), VPN+zapret одновременно (P1), выбор сервера по пропускной способности (P1), сетевые профили (P1), DNS-менеджер + проверка утечек (P0), экран соединений (P1), свои серверы из клиента (P2), синхронизация устройств (P2), legacy (P2).

## 2. Gap-анализ: чего не хватает Sora

### P0 — критично (проигрыш конкурентам уже сегодня)

1. **Android-клиент.** Главная дыра. Описание репозитория обещает Android, но в `app/` есть раннеры только `windows` и `linux`. Весь массовый рынок мобильных прокси-клиентов — v2rayNG, NekoBox, Hiddify, SFA, Karing — на Android. Без Android sora остаётся нишевым десктопным клиентом.
2. **QR импорт/шеринг.** У sora нет QR ни на импорт, ни на шеринг — при том что это базовый сценарий у v2rayNG, Nekoray, NekoBox, Hiddify, Shadowrocket, AmneziaVPN, v2rayN. Пользователь не может быстро перенести сервер с телефона на десктоп.
3. **Выбор сервера по пропускной способности.** Сейчас только задержка. v2rayN умеет массовый speed-test узлов. Уже в планах (P1) — поднять приоритет: «быстрейший по пингу» ≠ «быстрейший по скорости».
4. **DNS-менеджер и проверка утечек.** В планах (P0). У AmneziaVPN есть защита от DNS-утечек из коробки; у sora DNS-настройки разрознены. Для VPN-клиента это вопрос доверия.
5. **Экран мониторинга соединений.** API уже есть, UI — в планах (P1). Nekoray, Clash Verge, v2rayN, Shadowrocket показывают живые соединения — пользователи и провайдеры этого ждут.

### P1 — важно (паритет + задел)

6. **Синхронизация между устройствами.** В планах P2, но Karing (4 канала: iCloud/LAN/WebDAV/ZIP), Shadowrocket (iCloud), Clash Verge (WebDAV) уже это дают. Поднять до P1, иначе с выходом Android будет больно.
7. **Слой пользовательских override поверх подписки.** Clash Verge умеет merge-/script-профили (свои правки не затираются обновлением), Karing — единый набор правил поверх нескольких подписок. У sora JSON-подписки провайдера идут «как есть» + отдельно правила пользователя; явного механизма «мои правки поверх» нет.
8. **Цепочки прокси (proxy chains).** Есть у v2rayN и Shadowrocket. Для обхода цензуры (вход через одну страну, выход через другую) — востребовано.
9. **Сетевые профили.** Уже P1 в планах; никто из конкурентов не делает по-настоящему — шанс выделиться (см. раздел 3).
10. **iOS/macOS.** Долгострой, но там правят Shadowrocket ($2.99), Streisand, Hiddify, FoXray. Без Apple-платформ «лучшим клиентом» не стать.

### P2 — стратегическое

11. **Развёртывание своего сервера из клиента** (уже P2 в планах; у AmneziaVPN — киллер-фича).
12. **Расширения** (уже P1 в планах; ни у кого нет полноценно).
13. **Виджеты/быстрые тайлы/автоматизация** (Tasker/Shortcuts/intents) — гигиена для мобильного будущего.

### Что у Sora уже лучше конкурентов (защищать)

- Мульти-движок с автовыбором под сервер (только v2rayN рядом, но там нет capability-based автовыбора в рантайме).
- Бессерверный DPI-обход (zapret) — нет ни у кого.
- Kill switch, встающий до запуска ядра, + архитектура «конфиг через stdin, секреты в AES-256-GCM».
- Диагностика уровня HAR/PCAPNG/EVTX — нет ни у кого.
- Xray JSON-подписки (Remnawave) из коробки.
- 31 язык интерфейса.

## 3. Функции будущего (нет ни у кого или почти ни у кого)

1. **Умный выбор связки «сервер + движок» по живым замерам.** Сейчас sora выбирает движок по capabilities, а сервер — по пингу. Следующий шаг: фоново мерить для каждого сервера пропускную способность, джиттер и стабильность в разрезе движков и автоматически переключаться на лучшую связку. v2rayN умеет ручной массовый speed-test; непрерывного автоматического перебора нет ни у кого. Зачем: пользователь просто получает максимальную скорость без ручных тестов.
2. **Авто-тюнинг фрагментации под конкретный DPI.** Вместо ручных ползунков (как TLS Tricks у Hiddify) клиент сам зондирует провайдера: перебирает размеры фрагментов, uTLS-отпечатки и параметры, фиксирует, что проходит, и сохраняет профиль под этого ISP. Зачем: «подключил — и работает», ноль ручной настройки обхода блокировок.
3. **Детектор цензуры с упреждающим переключением.** Распознавание сигнатур DPI-блокировок в реальном времени (RST-инъекции, SNI-блокировка, троттлинг) и переключение сервера/транспорта до того, как пользователь заметил обрыв. Fallback-группы у sora уже есть; триггер по детекции, а не по факту обрыва, — новое.
4. **Сетевые профили с автоопределением сети.** Профили «дом / работа / мобильная / роуминг / другая страна» с автопереключением по SSID, шлюзу, ASN. Уже P1 в планах sora; никто из конкурентов не делает. Зачем: дома — всё через VPN, в офисе — split под корпоративные ресурсы, в роуминге — экономия трафика.
5. **E2E-сквозное P2P-синхронизирование без облака.** Синхронизация подписок и настроек между своими устройствами по прямому зашифрованному каналу (спаривание по QR, дальше LAN/интернет без сервера-посредника). У Karing есть LAN-синк; полностью бессерверный E2E-вариант — дифференциатор. Зачем: приватность + работает без аккаунтов.
6. **Автопроброс captive portal.** Детект страниц авторизации (отели, аэропорты) и временный выпуск трафика к порталу мимо VPN с возвратом после авторизации. Боль всех VPN-клиентов; в прокси-клиентах не реализовано ни у кого.
7. **Маршрутизация по классу трафика, а не только по правилам.** ML-классификация на устройстве: видео — через самый быстрый сервер, игры/звонки — через сервер с минимальным пингом, фоновое — напрямую. Статические правила у всех есть; адаптивной классификации нет.
8. **Развёртывание мультипротокольного сервера в один клик.** AmneziaVPN умеет разворачивать свой стек по SSH; sora могла бы разворачивать VLESS+REALITY/XHTTP/Hysteria2 на VPS пользователя с автоподбором параметров обфускации под его страну. Зачем: «свой VPN за 5 минут» для всего Xray/sing-box-стека, а не только протоколов Amnezia.
9. **Краудсорсинговая (opt-in, анонимная) карта DPI.** Клиенты добровольно сообщают, какие транспорты работают у их ISP/ASN; строится живая карта, новым пользователям в том же регионе сразу предлагается рабочая конфигурация. Чувствительно к приватности — только opt-in и агрегаты. Такого нет ни у кого.
10. **Ротация серверов по расписанию.** Kill-switch-безопасная смена сервера по таймеру/на сессию для приватности. Ни у кого из клиентских приложений нет.
11. **История пропускной способности серверов.** sora уже встраивает speedtest-сайты в приложение; следующий шаг — автоматические замеры скорости по каждому серверу с историей и графиком, данные питают фичу №1. У v2rayN есть разовый бенчмарк; истории и привязки к автовыбору нет.
12. **Семейный доступ к подписке.** Шаринг подписки членам семьи через E2E-зашифрованное приглашение (QR) с возможностью отзыва. У AmneziaVPN есть QR-шаринг доступа; управляемый шаринг с отзывом — новое. Зачем: провайдерам — меньше шаринга «налево», пользователям — удобно.
13. **Stealth-оценка конфигурации.** Проверка handshake-характеристик подключения против эталонных отпечатков браузеров (uTLS/QUIC) с выводом «оценки незаметности» сервера и предупреждением, если конфиг легко детектится. Такого нет ни у кого; напрямую про anti-DPI ценность.
14. **Горячие клавиши на профили/сценарии.** У sora уже есть хоткеи; расширение — бинды на конкретные серверы/режимы («Ctrl+Alt+1 — игры через Нидерланды»). Мелочь, но для десктопных power-user — любовь.
15. **Режим «штопор» для жёсткой цензуры.** Один тумблер, включающий каскад: цепочка через два сервера + максимальная фрагментация + авто-тюнинг (фичи №2, №8). Для пользователей из стран с агрессивным DPI — «нажми и забудь». Частично покрывается цепочками (gap №8), но как единый сценарий — новое.
