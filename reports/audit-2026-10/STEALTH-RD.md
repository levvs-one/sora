# STEALTH-RD: стелс-режимы sora (R&D тема 16/20)

Исследование: `sora/docs/stealth.md`. Код: `sora/core/engine/stealth/` (грейдер,
закоммичен). Смежные зоны: `core/obfs` (маскировка TLS, которые инициирует сам
кор), `core/wgobfusc` (каталог WG-обфускации, тема 5/20) — не дублировать.

## Принципы

1. **Не копируем закрытое** (NordWhisper, детали Proton-handshake), а
   комбинируем открытое лучше всех: ни один платный клиент не закрывает все
   три слоя DPI (отпечаток handshake, поведение потока, active probing)
   сразу — это окно sora.
2. **Параметры анти-детекта — в серверных конфигах/подписках**, не в клиенте
   (урок Proton Stealth: код открыт, параметры — нет).
3. **Обфускация обязана рандомизироваться** (урок AmneziaWG 1.x: статичные
   H-значения DPI выучивает как родные 1–4; только диапазоны 2.0).
4. **Честность оценки:** грейдер — эвристика для UI, никогда не «proof of
   undetectability». Не пишем свой VPN-протокол (антипример Lightway).

## P0 — недели, только свой код

- **P0-1. Грейдер `Grade(plan)`. DONE** (`bb79d39`). Проверяет публичные факты:
  plain WG (заголовки 1–4, 148/92 байта), нулевой AmneziaWG, статичные H1–H4,
  отсутствие uTLS-фингерпринта/фрагментации, голый Shadowsocks/Hysteria2/TUIC.
  Чейны через `Via` оцениваются только по внешнему плечу (паттерн Mullvad
  bridge). Следующий шаг: пробросить отчёт в diagnostics/UI (чужая зона —
  спекой, не кодом).
- **P0-2. `stealth.Bridge(inner, outer)`** — конструктор «WG через Shadowsocks»
  одной функцией: выставляет `Via`, выравнивает ID, валидирует что внешнее
  плечо — SS/obfs. Чистая функция + тесты, без изменений control/app.
- **P0-3. Матрица zapret-стратегий в docs** — какие флаги tpws против какого
  DPI (RU: split-pos+disorder+oob; SNI-блок: tlsrec; HTTP: hostcase/domcase).
  Только документация, без кода.
- **P0-4. Амнезиа-профиль из подписки (спека):** сервер публикует
  рекомендованные Jc/Jmin/Jmax/S/H-диапазоны, клиент подставляет. Параметры
  обязаны совпадать на обоих концах — значит, их место в подписке, а не
  захардкоженными в клиенте.

## P1 — месяцы, есть зависимости

- **P1-1. WG-over-TLS транспорт** (открытый аналог Proton Stealth): Go-сайдкар
  в core, заворачивающий WG-UDP в TLS-туннель на TCP/443. Честная оговорка:
  нужен серверный TLS-терминатор — работает с self-hosted и провайдерами,
  которые его поднимут; для чужих подписок — graceful fallback. Сложность M.
- **P1-2. `stealth_level` 0–3 в `AntiCensorship`** (proto + control + UI):
  0=выкл, 1=fragment+uTLS, 2=+AmneziaWG/цепочки, 3=+zapret-direct+PQ.
  Один свитч вместо ручной настройки десятка полей. Сложность M.
- **P1-3. PQ-handshake для WireGuard** (паттерн Mullvad `mullvad-upgrade-tunnel`):
  гибридный X25519+ML-KEM обмен PSK по обфусцированному каналу до поднятия WG.
  ML-KEM — NIST-стандарт, в Go через x/crypto/circl. Сложность M–H.
- **P1-4. Stealth-самопроверка в diagnostics:** активный прозвон собственного
  конфига (ClientHello похож на Chrome? фрагмент реально режет? handshake
  переживает DPI-эмуляцию?) — развитие идеи §3 №13 из competitor-analysis.
  Сложность M.

## P2 — кварталы, исследовательское

- **P2-1. Maybenot-шейпинг** (паттерн DAITA): паддинг до константного размера
  + cover-трафик. Честная оговорка: как и у Mullvad, требует поддержки на
  входном сервере (пустышки надо кому-то отбрасывать); без неё — только
  локальный паддинг исходящих. Спека, не код.
- **P2-2. Адаптивные камуфляж-профили под страну** (паттерн AmneziaWG 2.0:
  I-пакеты под QUIC/HTTP3), доставка через подписку.
- **P2-3. «Оценка незаметности» сервера в UI:** грейдер + краудсорсинг
  замеров, бейдж стелса у сервера в списке.
