# l10n queue — F9: sync screen wired to the sora-sync daemon

Ветка `bugfix/audit-2026-10-19`, только `app/`. Код уже ссылается на ключи ниже
через `S.of(context)`; сами `app/lib/l10n/*` НЕ трогать.

Применение: добавить ключи в `app/lib/l10n/app_en.arb` и `app/lib/l10n/app_ru.arb`
(английский — fallback для остальных языков), затем `flutter gen-l10n`.
Метаданные `@key` с `placeholders` — по образцу существующих
(`@syncRevokeConfirm`, `@syncLastSync`).

## Правка существующего ключа

`syncEmpty` сейчас обещает то, что приложение пока не делает
(`Pair another device to keep subscriptions, rules and settings in sync` —
мост документов «приложение → демон» ещё не зашит, см. отчёт F9). Честный текст:

| key | en (новое) | ru (новое) |
|---|---|---|
| `syncEmpty` | `No paired devices. Pair another device over the local network.` | `Нет спаренных устройств. Спарьте другое устройство в локальной сети.` |

Ключи `syncWhat` / `syncWhatBody` экраном больше не используются (список видов
документов убран из UI по контракту §4 — их нельзя синхронизировать честно,
пока не зашит мост документов); сами ключи из arb-файлов не удалять —
пригодятся, когда мост появится.

## Проверка после применения

`grep -rn "syncDaemonStarting\|syncUnavailableAndroid\|syncDaemonMissing\|syncDaemonFailed\|syncRetry\|syncThisDevice\|syncExpiresIn\|syncStopShowing\|syncCodeExpired\|syncNewCode\|syncJoining\|syncPairedWith\|syncSyncNow\|syncSyncResult\|syncLegacyCleared\|syncError\|syncErrAuth\|syncErrNotFound\|syncErrPairingActive\|syncErrUnreachable" app/lib --include='*.dart'` —
каждый ключ из таблицы должен использоваться, каждый `S.of(context).sync*Err*`
и остальные новые ключи из `app/lib/src/ui/sync.dart` / `app/lib/src/sync_api.dart` —
присутствовать в таблице.
