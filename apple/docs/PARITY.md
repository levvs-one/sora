# Паритет sora desktop → Apple: матрица фич (ЧЕРНОВИК)

Дата: **20.10.2026**. Статус: **черновик** — финал сверит другой
подотдел (сверка с фактическим кодом волны). Этот документ пишет
подотдел исследований и архитектуры: он фиксирует проектные статусы
и платформенные обоснования, а не факт реализации. Ни одна строка
ниже не утверждает «реализовано», если это не подтверждено кодом
волны; колонка статуса для кодовых фич по умолчанию —
**спроектировано**.

Архитектурные основания — в [ARCHITECTURE.md](ARCHITECTURE.md)
(таргеты §1, движок §2, NE-поведение §4, capability-лестница §5,
идентификаторы §3.4).

Статусы Apple:

- **Спроектировано** — есть архитектурное решение и контракт
  (ARCHITECTURE.md), кода в этой волне подотделом исследований
  не писалось; финальный статус ставит сверяющий подотдел.
- **Невозможно на платформе** — есть письменное обоснование;
  «невозможно» означает невозможно средствами публичных API в
  песочнице App Store/Direct-канала, а не «не успели».
- **Ограниченно** — подвид «спроектировано»: фича существует в
  урезанной платформенной форме, UI обязан показывать границу.

Колонка **А/Г/У** — оценка по критерию владельца
«адаптивно/гибко/удобно» (усиление мандата): насколько Apple-
реализация адаптируется к версиям/условиям и удобна относительно
десктопа. Шкала: `+` лучше десктопа, `=` паритет, `−` жёстче/беднее
десктопа. Где десктопная sora сама жёстче будущего Apple-клиента —
отмечено прямо в примечании.

Колонка **Детали** — пометка по «Стандарту мелочей»
(ARCHITECTURE.md §8: сетка 4/8pt и DesignTokens, константы анимаций,
глоссарий терминов, accessibility/Dynamic Type, правила обрезки
длинных строк, паритет тёмной/светлой тем, иконки по HIG):
`проверено` — экраны строки прошли проверку §8.8; `нет` — не
проверено (в этом черновике у всех строк: кода экранов в волне
исследований нет, пометку ставит сверяющий подотдел по факту);
`н/п` — неприменимо (строка без UI-поверхности / невозможна).

## Честные итоги черновика

1. Полный паритет достижим по ядру: протоколы/транспорты/TLS/DNS/
   маршруты/цепочки/подписки живут в sing-box-семантике, которую
   libbox несёт нативно.
2. Три принципиальных платформенных «невозможно»: zapret (обе
   формы), per-app split tunnel на iOS, расширения с кодом.
   Ещё два принципиальных «ограниченно»: kill switch (нет
   посмертной гарантии расширения) и системный прокси на iOS.
3. Два места, где Apple-клиент будет **лучше/гибче десктопа**:
   сетевые профили на системном on-demand и QR/виджеты/шорткаты
   как нативные поверхности. Одно место, где десктоп жёстче
   вынужденно, а Apple мягче случайно: Xray-специфика (ML-DSA-65,
   xray-profile, fallback/load-balance группы) на десктопе тоже
   живёт только на одном движке из трёх — Apple просто доводит
   это до одного движка вообще.
4. Неподтверждено и помечено по строкам: happ крипто-подписки,
   AWG 3.1/masquerade/naive в lx-libbox, process-правила на macOS,
   лимиты HWID-пути Happ на Apple.

## Аддендум координатора (приёмка 2026-10-20)

Черновик выше писался до кода; фактическое состояние после сдачи
подотделов и центральной приёмки:

- **Реализовано кодом в этой волне**: парсеры всех протоколов
  контракта и подписок (SoraCore, 39 тестов векторами из Go),
  генератор конфигов libbox для всех 8 протоколов + цепочки —
  **12/12 golden-конфигов проходят `sing-box check` настоящим
  бинарём sing-box-lx 1.14.3-lx.22** из `packaging/engines/engines.lock`
  (при приёмке найдены и исправлены два дефекта генератора: удалённый
  в sing-box 1.13 dns-аутбаунд и обязательный с 1.14
  `default_domain_resolver` по семантике Go `dns()`); хранилище
  профилей (аддитивные миграции v1→v2); iOS-приложение (7 экранов,
  виджет, AppIntents, deep links, честные состояния state.*);
  macOS-приложение (обе ветки меню-бара и автозапуска, виджет,
  AppIntents, Handoff, хоткей); PacketTunnel-провайдер за
  LibboxBridge-швом; локализация 31 локаль.
- **Колонка «Детали»**: у строк, покрытых экранами iOS/macOS, после
  приёмки — «проверено» (DesignTokens/Motion 160/180/220 мс,
  accessibility labels, truncation, пустые состояния, паритет тем —
  по отчётам подотделов и выборочной сверке координатора); у строк
  без экранов остаётся «нет»/«н/п» как в черновике.
- **Не реализовано и не замаскировано**: сборка в Xcode и
  Libbox.xcframework из форка sing-box-lx (спека — BUILD-MAC.md),
  SiriKit-фолбэк iOS 15 (спроектирован), legacy-таргеты iOS 13–14 /
  macOS 11–12 / 10.15 (обоснованы в ARCHITECTURE.md, кода нет).
